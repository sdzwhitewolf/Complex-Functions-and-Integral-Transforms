1.1 邻域与去心邻域
思考: 为什么要先讲"区域"?
实变函数中我们熟悉区间 $(a,b)$、$[a,b]$. 到了复平面, 一维的区间要换成二维的"区域". 后面所有重要概念 —— 解析、积分、级数、留数 —— 都要求函数"在某个区域内"讨论. 因此先把"区域"这个词的精确含义钉死, 是整门课的地基.
定义 (邻域与去心邻域)
设 $z_0$ 是复平面上一点, $\delta$ 为任意一个正数, 称点集
$$N_\delta(z_0) = \{\, z : |z - z_0| < \delta \,\}$$
为 $z_0$ 的一个 $\delta$ 邻域; 称点集
$$\mathring{N}_\delta(z_0) = \{\, z : 0 < |z - z_0| < \delta \,\}$$
为 $z_0$ 的一个 去心 $\delta$ 邻域.
几何直观: 邻域 $N_\delta(z_0)$ 就是以 $z_0$ 为圆心、$\delta$ 为半径的开圆盘(不含圆周); 去心邻域 $\mathring{N}_\delta(z_0)$ 则是这个开圆盘挖掉圆心$z_0$ 之后剩下的部分. "去心"二字看似小事, 却决定了极限定义的成败 —— 因为讨论 $\lim\limits_{z\to z_0} f(z)$ 时, 函数在 $z_0$ 这一点本身的值是否有定义、等于多少, 都与极限无关.

1.2 内点、开集
定义 (内点与开集)
设 $G$ 为一平面点集, $z_0 \in G$. 如果存在 $z_0$ 的一个邻域 $N_\delta(z_0)$, 使得 $N_\delta(z_0) \subset G$, 则称 $z_0$ 为 $G$ 的内点.
如果 $G$ 中每一点都是它的内点, 则称 $G$ 为开集.
要点辨析: 内点的关键在于"存在一个邻域完全包含在 $G$ 里面" —— 只要圆盘有一点点越出 $G$, 该点就不是内点. 因此圆周上的点 $|z|=1$ 不是开圆盘 $\{|z|<1\}$ 的内点, 但它是闭圆盘 $\{|z|\le 1\}$ 的内点吗? 也不是 —— 因为以它为中心的任何小圆盘都会有一部分落在外面.

1.3 区域、边界与闭区域
定义 (区域)
如果平面点集 $D$ 满足以下两个条件:
  1. $D$ 是一个开集;
  2. $D$ 是连通的 —— 即 $D$ 中任何两点都可以用一条完全属于 $D$ 的折线连结起来.
则称 $D$ 为一个区域.
$$\text{区域} \;=\; \text{连通的开集}$$
定义 (边界点、边界、闭区域)
设 $D$ 是复平面内的一个区域. 如果点 $P$ 不属于 $D$, 但在 $P$ 的任意小的邻域内总有 $D$ 中的点, 这样的 $P$ 称为 $D$ 的边界点.
$D$ 的所有边界点组成 $D$ 的边界. 区域 $D$ 与它的边界一起构成闭区域 (闭域), 记作 $\overline{D} = D \cup \partial D$.
注意
区域的边界可能是由几条曲线和一些孤立的点共同组成的, 不一定是一条光滑曲线. 例如圆环域 $\{1 < |z| < 2\}$ 的边界是两个圆; 而区域 $\{0 < |z| < 1\}$ 的边界除了单位圆周, 还要加上孤立点 $z=0$.
定义 (有界域与无界域)
如果存在正数 $M$, 使得对于一切 $D$ 中的点 $z$, 都有
$$|z| \le M$$
则称 $D$ 为有界域, 否则称为无界域.
例 1
判断下列区域是否有界?
$$\text{(1) 圆环域 } r < |z - z_0| < 2r; \quad \text{(2) 上半平面 } \operatorname{Im} z > 0;$$ $$\text{(3) 角形域 } 0 < \arg z < \frac{\pi}{4}; \quad \text{(4) 带形域 } a < \operatorname{Im} z < b \ (a < b).$$
【解】
(1) 对一切 $z \in \{\, r < |z - z_0| < 2r \,\}$ 有 $|z| \le |z - z_0| + |z_0| < 2r + |z_0|$, 取 $M = 2r + |z_0|$ 即可罩住, 故有界.
(2) 上半平面中可取 $z = \mathrm{i}M$ ($M$ 任意大), $|z| = M$ 可超过任何给定的 $M_0$, 故无界.
(3) 角形域 $\{\, 0 < \arg z < \frac{\pi}{4} \,\}$ 是张角为 $\frac{\pi}{4}$ 的无限楔形区域, 沿角平分线方向可以走得任意远, 故无界.
(4) 带形域中可取 $z = M + \mathrm{i}\,\frac{a+b}{2}$ ($M$ 任意大), 故无界.
结论: (1) 有界; (2)(3)(4) 无界.
可见"有界"要求区域能被某个圆盘 $|z| \le M$ 整个罩住; 只要沿某个方向能无限延伸, 就是无界.

1.4 平面曲线
定义 (连续曲线的复数表示式)
如果 $x(t)$ 和 $y(t)$ 是两个连续的实变函数, 则方程组
$$x = x(t), \qquad y = y(t) \qquad (\alpha \le t \le \beta)$$
代表一条平面曲线. 令 $z(t) = x(t) + \mathrm{i}y(t)$, 则称之为平面曲线的复数表示式.
例 2
写出单位圆周 $|z| = 1$ 与抛物线 $y = x^2$ $(0 \le x \le 1)$ 的复数表示式.
【解】
(1) 单位圆周 $|z| = 1$: 取 $x = \cos t$, $y = \sin t$, $0 \le t \le 2\pi$, 则 $$z(t) = \cos t + \mathrm{i}\sin t = \mathrm{e}^{\mathrm{i}t}, \qquad 0 \le t \le 2\pi.$$
(2) 抛物线 $y = x^2$ $(0 \le x \le 1)$: 直接令 $t = x$ 作参数, 则 $y = t^2$, 故 $$z(t) = t + \mathrm{i}\,t^2, \qquad 0 \le t \le 1.$$
参数 $t$ 可以理解为"时间", 而 $z(t)$ 是动点在不同时刻的位置 —— 曲线就是动点运动的轨迹. 反过来, 同一条曲线的复数表示式并不唯一, 参数选得不同, 写法就不同.
定义 (光滑曲线与按段光滑曲线)
如果在区间 $[\alpha, \beta]$ 上, $z(t)$ 的实部 $x(t)$ 和虚部 $y(t)$ 都有连续的导数, 而且
$$[x'(t)]^2 + [y'(t)]^2 \ne 0 \qquad (\text{即 } z'(t) \ne 0)$$
则称曲线 $z = z(t)$ 光滑.
由几段依次相接的光滑曲线所组成的曲线称为按段光滑曲线.
为什么要求 $z'(t) \ne 0$? 因为 $z'(t)$ 是曲线的切向量. 若在某点 $z'(t)=0$, 该点处切线方向消失, 曲线可能出现尖点或静止, 不再是"光滑"的. 例如 $z(t) = t^3 + \mathrm{i}t^3$ 在 $t=0$ 处 $z'(0)=0$, 曲线在该点有一个尖角, 因此不光滑.
定义 (简单曲线与简单闭曲线)
设 $C:\ z = z(t)$ ($\alpha \le t \le \beta$) 为一条连续曲线, $z(\alpha)$ 与 $z(\beta)$ 分别为 $C$ 的起点与终点.
对于满足 $\alpha < t_1 < \beta$, $\alpha < t_2 < \beta$ 的 $t_1$ 和 $t_2$, 当 $t_1 \ne t_2$ 而有 $z(t_1) = z(t_2)$ 时, 点 $z(t_1)$ 称为曲线 $C$ 的重点.
没有重点的曲线 $C$ 称为简单曲线 (或 Jordan 曲线).
如果简单曲线的起点与终点重合, 即 $z(\alpha) = z(\beta)$, 则称曲线 $C$ 为简单闭曲线.
注意
"简单"的含义就是"自身不相交, 不重复经过同一点". 理解时可记为: 简单曲线是"一笔画且不回头"的曲线; 简单闭曲线则是"一笔画、不回头、且首尾相接围成一圈"的曲线.
例 3
判断下列曲线是否为简单曲线? 是否为闭曲线?
$$\text{(1) } z = \mathrm{e}^{\mathrm{i}t} \ (0 \le t \le 3\pi); \qquad \text{(2) } z = t + \mathrm{i}t^2 \ (0 \le t \le 2);$$ $$\text{(3) } z = \cos t + \mathrm{i}\sin t \ (0 \le t \le 4\pi); \qquad \text{(4) } z = a\cos t + \mathrm{i}\,b\sin t \ (0 \le t \le 2\pi,\ a, b > 0,\ a \ne b).$$
【解】
(1) $z = \mathrm{e}^{\mathrm{i}t}$ $(0 \le t \le 3\pi)$: 动点沿单位圆绕了 $1\frac{1}{2}$ 圈. 当 $t_2 = t_1 + 2\pi$ ($0 < t_1 \le \pi$) 时 $z(t_1) = z(t_2)$, 出现重点, 故不简单; 又起点 $z(0) = 1 \ne z(3\pi) = -1$, 首尾不重合, 故不闭. 结论: 不简单, 不闭.
(2) $z = t + \mathrm{i}t^2$ $(0 \le t \le 2)$: 即抛物线 $y = x^2$ 的一段. 若 $z(t_1) = z(t_2)$, 则实部相等给出 $t_1 = t_2$, 无重点, 故简单; 又 $z(0) = 0 \ne z(2) = 2 + 4\mathrm{i}$, 故不闭. 结论: 简单, 不闭.
(3) $z = \cos t + \mathrm{i}\sin t = \mathrm{e}^{\mathrm{i}t}$ $(0 \le t \le 4\pi)$: 动点沿单位圆绕了 $2$ 圈, 当 $t_2 = t_1 + 2\pi$ 时 $z(t_1) = z(t_2)$, 有重点, 故不简单; 但 $z(0) = z(4\pi) = 1$, 首尾重合, 故闭. 结论: 不简单, 闭.
(4) $z = a\cos t + \mathrm{i}\,b\sin t$ $(0 \le t \le 2\pi)$: 即椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$. 若 $z(t_1) = z(t_2)$, 由实部 $a\cos t_1 = a\cos t_2$ 与虚部 $b\sin t_1 = b\sin t_2$, 在 $[0, 2\pi]$ 内只能 $t_1 = t_2$ (一个周期内椭圆上每点只经过一次), 无重点, 故简单; 且 $z(0) = z(2\pi) = a$, 首尾重合, 故闭. 结论: 简单, 闭 —— 是一条简单闭曲线.
判断口诀: 先看有没有"重点"(自交), 再看首尾是否重合. 注意 (1) 与 (3) 的对比: 同是圆周, 转的圈数不同, "简单"与"闭"的结论组合就不同.
简单闭曲线的性质 (Jordan 曲线定理)
任意一条简单闭曲线 $C$ 将复平面唯一地分成三个互不相交的点集: 曲线 $C$ 的内部、$C$ 的外部, 以及 $C$ 本身 (边界).
这个看似"显然"的事实, 严格证明却相当困难 —— 它是拓扑学的重要起点.

1.5 单连通域与多连通域
定义 (单连通域与多连通域)
复平面上的一个区域 $B$, 如果在其中任作一条简单闭曲线, 而曲线的内部总属于 $B$, 就称为单连通域.
一个区域如果不是单连通域, 就称为多连通域.
单连通域 (单连域)
区域内没有"洞". 其中的任何一条简单闭曲线围成的内部都完全留在区域内.
直观判据: 在区域内任意画一个圈, 圈里圈外都在区域里, 收缩成一个点也不会碰到区域外.
例子: 圆盘 $\{|z|<1\}$、上半平面、任何凸区域.
多连通域 (多连域)
区域内有"洞" (或者被割开). 存在一条简单闭曲线, 它围住的内部有一部分不在区域内.
直观判据: 有些圈把"洞"圈了进去, 于是圈内的某些点落在区域外.
例子: 圆环域 $\{1<|z|<2\}$ (一个洞, 二连域).
例 4
指明下列不等式所确定的区域: 是有界的还是无界的? 是单连通的还是多连通的?
$$\text{(1) } \operatorname{Re}(z) > 1; \qquad \text{(2) } \frac{\pi}{4} < \arg z < \frac{\pi}{3}; \qquad \text{(3) } x^2 + y^2 > 1.$$
【解】
(1) 令 $z = x + \mathrm{i}y$, $\operatorname{Re}(z) > 1$ 即 $x > 1$ —— 直线 $x = 1$ 右侧的半平面. 它可以无限延伸, 故无界; 其中任何简单闭曲线的内部仍在该半平面内 (没有"洞"), 故单连通. 结论: 无界的单连通域.
(2) $\frac{\pi}{4} < \arg z < \frac{\pi}{3}$ 是以原点为顶点、张角为 $\frac{\pi}{3} - \frac{\pi}{4} = \frac{\pi}{12}$ 的角形域. 它沿射线方向无限延伸, 故无界; 且无洞, 故单连通. 结论: 无界的单连通域.
(3) $x^2 + y^2 > 1$ 即 $|z| > 1$ —— 单位圆的外部. 它可以无限延伸, 故无界; 但在区域内任作圆周 $|z| = 2$ (它整个落在区域内), 其内部却含有单位圆盘 $\{|z| \le 1\}$ 这一部分不属于区域的点 —— 相当于圈住了 $z = 0$ 处的一个"洞", 故多连通. 结论: 无界的多连通域.
注意本题与例 1 的对比: $\{|z|>1\}$ 虽然是"圆的外部", 却不是单连通的 —— "外部区域"围着圆盘这个洞. 有界性与单连通性是两个独立的性质.

常见误区
"有界"与"单连通"是两个互不相关的性质, 不要混淆.
  • 圆盘 $\{|z|<1\}$: 有界 且 单连通;
  • 圆环 $\{1<|z|<2\}$: 有界 但 多连通;
  • 上半平面: 无界 但 单连通;
  • 带形域 $\{1<\operatorname{Im}z<3\}$: 无界 且 单连通;
  • $\{0<|z|<1\}$: 有界 但 多连通 (被挖去一个点, 相当于一个"点洞").
2.1 复变函数的定义
定义 (复变函数)
设 $G$ 是复平面上的一个集合, 对于 $G$ 中的每一个 $z$, 按照一个确定的法则, 有一个或多个复数 $w$ 的值与之对应, 则称 $w$ 为定义在 $G$ 上复变数 $z$ 的复变函数, 记作
$$w = f(z), \qquad z \in G.$$
单值函数
对于 $G$ 中的每个 $z$, 有且仅有唯一一个 $w$ 与之对应, 则称函数 $w = f(z)$ 是单值的.
例: $w = z^2$, $w = \mathrm{e}^z$, $w = \frac{1}{z}$.
多值函数
对于 $G$ 中的每个 $z$, 有两个或两个以上 $w$ 与之对应, 则称函数 $w = f(z)$ 是多值的.
例: $w = \sqrt{z}$ (两个值), $w = \sqrt[3]{z}$ (三个值), $w = \operatorname{Arg} z$ (无穷多值).
术语: 集合 $G$ 称为 $f(z)$ 的定义集合; 与 $G$ 中所有 $z$ 对应的一切 $w$ 值所成的集合 $G^*$ 称为函数值集合.
后面重点研究的是单值函数; 对多值函数 (如根式、对数), 我们将通过"分出单值分支"的办法来处理.
2.2 复变函数与两个二元实变函数
核心对应关系
给定自变量 $z = x + \mathrm{i}y$ 的值, 相当于给定两个实数 $x,\ y$. 而复变函数 $w = f(z)$ 也确定两个实数 $u,\ v$, 从而
$$w = f(z) = u(x,y) + \mathrm{i}\,v(x,y).$$
于是复变函数 $w$ 与自变量 $z$ 之间的关系, 相当于两个关系式:
$$u = u(x, y), \qquad v = v(x, y).$$
重要结论
一个复变函数 $w = f(z)$ 对应于一对二元实变函数 $u(x,y)$、$v(x,y)$. 反过来, 给出一对二元实变函数 $u(x,y)$、$v(x,y)$, 就确定了一个复变函数 $f(z) = u(x,y) + \mathrm{i}v(x,y)$.
这个"降维"对应是整门课把复变问题转化为实变问题的总开关 —— 极限、连续、导数、积分都会用到它.
例 5
设 $w = z^2$, 求它所对应的两个二元实变函数.
【解】
令 $z = x + \mathrm{i}y$, $w = u + \mathrm{i}v$, 则 $$w = z^2 = (x + \mathrm{i}y)^2 = x^2 + 2xy\,\mathrm{i} + (\mathrm{i}y)^2 = (x^2 - y^2) + 2xy\,\mathrm{i}.$$ 于是函数 $w = z^2$ 对应于两个二元实变函数
$$u(x,y) = x^2 - y^2, \qquad v(x,y) = 2xy.$$

这对函数在后续章节会反复出现: $u = x^2 - y^2$ 的"鞍形等值线"与 $v = 2xy$ 的"双曲等值线"正交, 这正是第二章"解析函数实虚部调和"的第一个例证.
2.3 复变函数的映射 (几何) 定义
定义 (映射)
函数 $w = f(z)$ 在几何上可看作把 $z$ 平面上的一个点集 $G$ 变到 $w$ 平面上的一个点集 $G^*$ 的映射.
如果 $G$ 中的点 $z_0$ 被映射 $w = f(z)$ 映射成 $G^*$ 中的点 $w_0$, 则 $w_0$ 称为 $z_0$ 的像 (映像), 而 $z_0$ 称为 $w_0$ 的原像.
两个平面: 复变函数的研究需要同时看两个复平面 —— 左边 $z$ 平面 (自变量所在), 右边 $w$ 平面 (函数值所在). 函数 $f$ 就是在这两个平面之间建立对应的一台"复印机"或"变形器".
例 6
说明映射 $w = z^2$ 把 $z$ 平面上与正实轴交角为 $\theta$ 的角形域映射成什么区域.
【解】
设 $z = r \mathrm{e}^{\mathrm{i}\varphi}$, 则 $w = z^2 = r^2 \mathrm{e}^{\mathrm{i}2\varphi}$, 于是
$$\operatorname{Arg} w = \operatorname{Arg} z^2 = 2\operatorname{Arg} z.$$
即经过映射后, 每一点的辐角都加倍 (模 $r$ 变为 $r^2$, 但模的缩放不影响区域形状).
因此, $z$ 平面上与正实轴交角为 $\theta$ 的角形域 $\{\,0 < \arg z < \theta\,\}$, 被映射成 $w$ 平面上与正实轴交角为 $2\theta$ 的角形域 $\{\,0 < \arg w < 2\theta\,\}$ —— 张角扩大了一倍.
特别地, 取 $\theta = \frac{\pi}{4}$, 则像为张角 $\frac{\pi}{2}$ 的角形域; 取 $\theta = \frac{\pi}{2}$ (上半平面), 则像为整个平面挖去正实轴 (辐角被拉满一圈).
一般地, $w = z^n$ 把张角为 $\theta_0$ 的角形域映射成张角为 $n\theta_0$ 的角形域 —— 角在原点处被放大 $n$ 倍, 这正是 $z=0$ 处"保角性"失效的原因.

拓展: 为什么"映射"的观点如此重要?
把复变函数看成映射, 是复分析区别于实分析的根本视角. 实变函数 $y=f(x)$ 的图象画在二维平面上; 而复变函数需要两个复平面 (共四维实坐标), 无法直接画出图象, 只能画原像集 → 像集的对应关系.
正是这个几何观点, 孕育了后来的共形映射理论 (第六章): 解析函数在导数不为零处保持角度不变, 于是可以把复杂的区域"扳"成简单的标准区域 (如圆盘、上半平面), 从而把困难区域上的问题转化为标准区域上的问题.
常见误区
"函数值集合 $G^*$" 与 "定义集合 $G$" 不要混为一谈. $z$ 平面的点属于 $G$, $w$ 平面的点属于 $G^*$, 二者通常不在同一个平面里. 求"像集"时, 应把 $z$ 的取值范围代入 $f$ 后解出 $w$ 的对应范围, 而不能直接拿 $z$ 的范围当作 $w$ 的范围.
3.1 极限的定义
思考: 复变函数的极限比实变函数"苛刻"在哪里?
实轴上 $x \to x_0$ 只有两个方向 (左、右). 而在复平面上, $z \to z_0$ 有无穷多个方向 —— 可以沿任何一条曲线接近.
这就要求 $f(z)$ 沿所有可能的路径都趋于同一个数. 条件变强了, 但也因此, "证明极限不存在"变得容易多了: 只要找到两条路径给出不同的结果即可.
定义 (极限的 $\varepsilon$-$\delta$ 语言)
设函数 $w = f(z)$ 在 $0 < |z - z_0| < \rho$ 内有定义. 如果存在一个确定的数 $A$, 对于任意给定的 $\varepsilon > 0$, 相应地必有一个正数 $\delta$ ($\delta < \rho$), 使得当
$$0 < |z - z_0| < \delta$$
时, 有
$$|f(z) - A| < \varepsilon,$$
那么称 $A$ 为 $f(z)$ 当 $z$ 趋向 $z_0$ 时的极限, 记作
$$\lim\limits_{z \to z_0} f(z) = A \qquad \text{或} \qquad f(z) \to A \quad (z \to z_0).$$
几何意义
当 $z$ 进入 $z_0$ 的充分小的去心邻域时, 它的函数值 $f(z)$ 就落入 $A$ 的预先给定的小邻域内.
关键注释
$z$ 趋于 $z_0$ 的方式是任意的. 就是说, 无论 $z$ 从什么方向、以何种方式趋向于 $z_0$, $f(z)$ 都要趋向于同一个常数.
由此得到判定极限不存在的有力工具: 若沿两条不同的路径 $z \to z_0$ 时 $f(z)$ 趋于不同的值, 则极限不存在.

3.2 极限的计算: 两个基本定理
定理一 (极限与实部虚部的关系)
设函数 $f(z) = u(x,y) + \mathrm{i}\,v(x,y)$, $z_0 = x_0 + \mathrm{i}y_0$, $A = a + \mathrm{i}b$, 则
$$\lim\limits_{z \to z_0} f(z) = A$$
的充要条件是
$$\lim\limits_{\substack{x \to x_0 \\ y \to y_0}} u(x,y) = a, \qquad \lim\limits_{\substack{x \to x_0 \\ y \to y_0}} v(x,y) = b.$$
定理一的价值: 该定理表明, 复变函数的极限问题可转化为求两个实变函数的极限问题. 这样就把复变函数的极限"降维"成我们熟悉的二元实函数极限, 大大降低了计算难度.
证明思路
  • (1) 必要性由 $\lim\limits_{z\to z_0} f(z) = A$ 知, 对任意 $\varepsilon>0$ 存在 $\delta>0$, 当 $0<|z-z_0|<\delta$ 时 $|f(z)-A|<\varepsilon$. 注意到 $|u - a| \le |f(z) - A|$ 与 $|v - b| \le |f(z) - A|$, 即可推出 $u \to a$, $v \to b$.
  • (2) 充分性反过来, 若 $u \to a$ 且 $v \to b$, 则对任意 $\varepsilon>0$ 存在 $\delta_1,\delta_2>0$, 取 $\delta = \min\{\delta_1,\delta_2\}$, 由 $$|f(z) - A| = |(u-a) + \mathrm{i}(v-b)| \le |u-a| + |v-b| < \varepsilon$$ 即得 $f(z) \to A$. 证毕.
为什么用 $|u-a| \le |f-A|$?
因为 $|f - A|^2 = (u-a)^2 + (v-b)^2$, 而 $(u-a)^2 \le |f-A|^2$, 开方即得. 这一步是整个证明的枢纽: 整体小蕴含分量小 (必要性), 而 分量之和小蕴含整体小 (充分性).
定理二 (极限的四则运算)
如果 $\lim\limits_{z \to z_0} f(z) = A$, $\lim\limits_{z \to z_0} g(z) = B$, 则
$$\lim\limits_{z\to z_0}\big[\,f(z) \pm g(z)\,\big] = A \pm B; \qquad \lim\limits_{z\to z_0}\big[\,f(z)\,g(z)\,\big] = A\,B;$$ $$\lim\limits_{z \to z_0} \frac{f(z)}{g(z)} = \frac{A}{B} \qquad (B \ne 0).$$
3.3 极限不存在的经典例子
例 7
证明函数 $f(z) = \frac{\operatorname{Re}(z)}{|z|}$ 当 $z$ 趋于 $0$ 时的极限不存在.
【解法一】代数形式 (转化为二元实函数极限)
令 $z = x + \mathrm{i}y$, 则 $\operatorname{Re}(z) = x$, $|z| = \sqrt{x^2 + y^2}$, 于是 $$f(z) = \frac{x}{\sqrt{x^2 + y^2}}, \qquad \text{即} \quad u(x,y) = \frac{x}{\sqrt{x^2+y^2}}, \quad v(x,y) = 0.$$ 让 $z$ 沿直线 $y = kx$ 趋于原点: $$\lim\limits_{\substack{x \to 0 \\ y = kx}} u(x, y) = \lim\limits_{x \to 0} \frac{x}{\sqrt{x^2 + k^2x^2}} = \lim\limits_{x \to 0} \frac{\pm 1}{\sqrt{1 + k^2}} = \pm\frac{1}{\sqrt{1+k^2}}.$$ 结果依赖于斜率 $k$ 的符号与大小: 取 $k = 0$ (沿实轴) 得 $\pm 1$; 取 $k = 1$ 得 $\pm\frac{1}{\sqrt{2}}$. 不同路径给出不同极限, 故 $\lim\limits_{z \to 0} f(z)$ 不存在.
【解法二】利用复数的三角表示式
设 $z = r(\cos\theta + \mathrm{i}\sin\theta) = r\mathrm{e}^{\mathrm{i}\theta}$, 则 $\operatorname{Re}(z) = r\cos\theta$, $|z| = r$, 于是 $$f(z) = \frac{r\cos\theta}{r} = \cos\theta.$$ $f(z)$ 的值只依赖方向 $\theta$, 与距离 $r$ 无关. 当 $z$ 沿着不同的射线 $\theta = \text{常数}$ 趋于零时, $f(z) \to \cos\theta$ 趋于不同的值:
  • 沿正实轴 $\arg z = 0$: $f(z) \to \cos 0 = 1$;
  • 沿正虚轴 $\arg z = \frac{\pi}{2}$: $f(z) \to \cos\frac{\pi}{2} = 0$;
  • 沿负实轴 $\arg z = \pi$: $f(z) \to \cos\pi = -1$.
极限值随路径而变, 故极限不存在.
解法二更简洁, 也更深刻地揭示了本质: $f(z)$ 把整个平面"压"到了区间 $[-1, 1]$ 上, 方向不同的点被压到不同的值.

路径逼近实验台 核心交互

拖动滑块改变接近原点的方向角 $\theta$, 观察函数值 $f(z)=\frac{\operatorname{Re}(z)}{|z|}=\cos\theta$ 在 $w$ 平面上的落点 (只在实轴区间 $[-1,1]$ 上滑动). 无论距离多近, 只要方向一变, 函数值就变 —— 这就是"沿不同路径得到不同极限"的几何证据.

拓展对照: 另一个经典函数 $f(z) = \bar z / z$
与例 7 同类的还有 $f(z) = \frac{\bar z}{z}$: 设 $z = r\mathrm{e}^{\mathrm{i}\theta}$, 则 $f(z) = \mathrm{e}^{-2\mathrm{i}\theta}$, 同样只依赖方向、不依赖距离, 沿不同射线趋于不同值 (沿正实轴 $\to 1$, 沿正虚轴 $\to -1$), 故在原点处极限也不存在.
与之对比, $f(z) = z$ 的极限存在 (为 $0$), 因为沿任何方向都有 $f(z) = r\mathrm{e}^{\mathrm{i}\theta} \to 0$.
一般判据: 若 $f(z)$ 能写成 $r^k \cdot g(\theta)$ 的形式, 当 $k > 0$ 时极限存在 (为 $0$); 当 $k = 0$ 时极限存在当且仅当 $g(\theta)$ 与 $\theta$ 无关.
常见误区
用一条路径算出极限值, 不能证明极限存在!
  • 要证明极限存在: 必须证明沿任意路径都趋于同一个值 (通常用 $\varepsilon$-$\delta$ 或定理一、定理二);
  • 要证明极限不存在: 只需找出两条路径给出不同结果 (反证法);
  • 常见的错误是"沿 $y = kx$ 算出一个与 $k$ 无关的值, 就断言极限存在". 沿直线的所有结果一致, 仍可能有沿抛物线、沿螺旋线的结果不同!
4.1 连续性的定义
定义 (连续)
如果
$$\lim\limits_{z \to z_0} f(z) = f(z_0),$$
则称 $f(z)$ 在 $z_0$ 处连续.
若 $f(z)$ 在区域 $D$ 内各点都连续, 那么称 $f(z)$ 在 $D$ 内连续.
连续的三要素: 上式实际上同时要求三件事 ——
  1. $f$ 在 $z_0$ 点有定义 (即 $f(z_0)$ 存在);
  2. $\lim\limits_{z\to z_0} f(z)$ 存在 (且与路径无关);
  3. 两者相等.
任何一条不满足, 该点就不连续. 这也解释了为什么研究连续性必须"先讲极限".
定理一 (连续与实部虚部的关系)
$f(z) = u(x,y) + \mathrm{i}v(x,y)$ 在 $z_0 = x_0 + \mathrm{i}y_0$ 处连续的充要条件是: $u(x,y)$ 与 $v(x,y)$ 都在 $(x_0, y_0)$ 处连续.
例 8
讨论 $f(z) = \ln(x^2 + y^2) + \mathrm{i}\,(x^2 - y^2)$ (其中 $z = x + \mathrm{i}y$) 在复平面内的连续性.
【解】
$f(z) = u(x,y) + \mathrm{i}\,v(x,y)$, 其中 $$u(x,y) = \ln(x^2 + y^2), \qquad v(x,y) = x^2 - y^2.$$ 看实部: $x^2 + y^2$ 处处连续且取正值, 对数函数在 $(0, +\infty)$ 上连续, 由复合函数的连续性知 $u = \ln(x^2+y^2)$ 在除原点外处处连续 (在原点处 $x^2+y^2 \to 0^+$, $\ln \to -\infty$, 无定义).
看虚部: $v = x^2 - y^2$ 是多项式, 处处连续.
由定理一, $f(z)$ 在复平面内除原点外处处连续.
判断复变函数的连续性, 就是这样"拆成实虚部、逐个检验、再用定理一合起来" —— 与极限的定理一如出一辙.
例 9
证明 $f(z) = \frac{1}{z}$ 在复平面内除原点外处处连续.
【解】
设 $z = x + \mathrm{i}y \ne 0$, 则 $$\frac{1}{z} = \frac{\bar z}{|z|^2} = \frac{x}{x^2+y^2} - \mathrm{i}\,\frac{y}{x^2+y^2},$$ 即 $$u = \frac{x}{x^2+y^2}, \qquad v = -\frac{y}{x^2+y^2}.$$ 由于 $x^2 + y^2$ 除原点外处处连续且不为零, 由连续函数的商的连续性知 $u,\ v$ 在除原点外的每一点都连续. 再由定理一, $f(z) = \frac{1}{z}$ 在复平面内除原点外处处连续.
定理二 (连续函数的运算法则)
  1. 在 $z_0$ 连续的两个函数 $f(z)$ 与 $g(z)$ 的和、差、积、商 (分母在 $z_0$ 不为零) 在 $z_0$ 处仍连续;
  2. 如果函数 $\zeta = g(z)$ 在 $z_0$ 连续, 函数 $w = f(\zeta)$ 在 $\zeta_0 = g(z_0)$ 连续, 则复合函数 $w = f[g(z)]$ 在 $z_0$ 处连续.
注: 连续函数的四则运算、复合运算都成立.
4.2 常见函数的连续性
有理整函数与有理分式函数
(1) 有理整函数 (多项式)
$$P(z) = a_0 + a_1 z + a_2 z^2 + \cdots + a_n z^n$$
在复平面内处处连续.
(2) 有理分式函数
$$R(z) = \frac{P(z)}{Q(z)} \qquad (P, Q \text{ 都是多项式})$$
在复平面内使分母不为零的点处也是连续的.
例 10
讨论 $f(z) = \frac{z^2 - 1}{z^2 + 1}$ 的连续范围.
【解】
分子 $P(z) = z^2 - 1$ 是多项式, 处处连续.
分母 $Q(z) = z^2 + 1 = (z - \mathrm{i})(z + \mathrm{i})$, 它在 $z = \pm \mathrm{i}$ 处为零.
于是由定理二, $f(z)$ 在复平面内除 $z = \pm \mathrm{i}$ 外的所有点连续.
函数在曲线上的连续与有界性
如果函数 $f(z)$ 在曲线 $C$ 上满足: 对 $C$ 上一点 $z_0$,
$$\lim\limits_{\substack{z \to z_0 \\ z \in C}} f(z) = f(z_0),$$
则称 $f(z)$ 在曲线 $C$ 上 $z_0$ 点连续. 若在 $C$ 上每一点都连续, 就称 $f(z)$ 在曲线 $C$ 上连续.
定理 (曲线上的有界性): 在闭曲线或包括端点在内的曲线上连续的函数, 在曲线上是有界的 —— 即存在正数 $M$, 使得在曲线上有
$$|f(z)| \le M.$$
这个定理有什么用? 它与实变函数中"闭区间上连续函数有界"的结论完全对应: 曲线相当于"定义域", 闭曲线或带端点的曲线相当于"有界闭集", 连续函数在其上不会"跑到无穷". 它是第三章积分理论的第一块基石 —— 曲线积分 $\displaystyle\int_C f(z)\,\mathrm{d}z$ 的定义就要求 $f$ 在 $C$ 上有界 (否则积分和可能无界).

常见误区
"$f$ 在 $z_0$ 有极限"与"$f$ 在 $z_0$ 连续"不是一回事.
  • 连续 = 极限存在 且 等于该点的函数值;
  • 函数可以在某点有极限但不连续 (可去间断点, 例如 $f(z) = \frac{z^2}{z}$ 在 $z=0$ 处有极限 $0$ 但无定义);
  • 函数也可以在 $z_0$ 有定义、有极限, 但两者不等 —— 仍不连续;
  • 注意"$\lim\limits_{z\to z_0} f(z) = f(z_0)$"中的极限过程是 $z \to z_0$, 不是 $z \to \infty$ 或单侧极限.

6. 点集 $D = \{\, z : \operatorname{Re}(z) > 0 \,\}$ 是 ( )
A. 有界的单连通域
B. 有界的多连通域
C. 无界的单连通域
D. 无界的多连通域
正解 C. 右半平面是开集且连通(任两点可用直线段相连), 无"洞", 故单连通; 但它可无限延伸, 故无界.
7. 关于集合 $G = \{\, z : |z| < 1 \,\} \cup \{\, z : |z - 3| < 1 \,\}$, 正确的是 ( )
A. 是开集, 但不是区域
B. 是区域
C. 是有界闭区域
D. 不是开集
正解 A. $G$ 是两个互不相交的开圆盘之并, 是开集; 但因两部分不连通(无法用完全落在 $G$ 内的折线相连), 所以不是区域. "区域 = 连通的开集".
8. 曲线 $z(t) = t + \mathrm{i}\,t^{2}$ ($0 \le t \le 1$) 是 ( )
A. 简单闭曲线
B. 不光滑的简单曲线
C. 光滑的简单曲线
D. 不是简单曲线
正解 C. $z'(t) = 1 + 2t\mathrm{i} \ne 0$ 在 $[0,1]$ 上恒成立(连续且不为零), 故光滑; 且 $t\mapsto(t,t^2)$ 是抛物线上一段, 无重点、首尾不重合, 故简单.
9. 设 $f(z) = \frac{\bar z}{z}$ ($z \ne 0$), 则 $\lim\limits_{z \to 0} f(z)$ ( )
A. 等于 $0$
B. 等于 $1$
C. 不存在
D. 等于 $-1$
正解 C. 取 $z = r\mathrm{e}^{\mathrm{i}\theta}$, 则 $f = \frac{r\mathrm{e}^{-\mathrm{i}\theta}}{r\mathrm{e}^{\mathrm{i}\theta}} = \mathrm{e}^{-2\mathrm{i}\theta}$, 与 $r$ 无关而只依赖辐角. 沿 $\theta = 0$(实轴) 有 $f \to 1$; 沿 $\theta = \frac{\pi}{2}$(虚轴) 有 $f \to \mathrm{e}^{-\mathrm{i}\pi} = -1$. 两方向极限不同, 故 $\lim\limits_{z\to 0} f(z)$ 不存在. 这是"路径不同 ⇒ 无极限"的经典例子.

A. 有界
B. 必可取到最大值但不能取到最小值
C. 一定解析
D. 一定可导
正解 A. 连续函数在有界闭集(闭曲线是有界闭集)上必有界, 这是数学分析中的有界性定理在复变函数中的推广(实部、虚部分别用该定理). 连续性只保证有界, 与解析、可导无关.

本节的核心概念 —— 区域、连通、映射、极限、连续 —— 看似抽象, 却处处体现着"从局部把握整体"与"用无穷逼近有限"的认识论. 中华民族自古就有"整体观"与"变易观"的思想传统; 现代数学的严谨化, 则是人类理性精神的共同结晶.
6.1 数学家的故事: 从"直觉"到"严格"
柯
柯西 (Augustin-Louis Cauchy, 1789 — 1857)
法国数学家 · 复分析的奠基人 · 《分析教程》(1821)

今天我们用得最顺手的 $\varepsilon$-$\delta$ 极限语言、"连续""导数"的严格定义, 都出自柯西. 在他之前, 欧拉、拉格朗日等大师用好成绩"算"出了大量正确结果, 但"无穷小"究竟是不是零, 谁也说不清.

柯西第一次把"极限"从一种计算动作提炼为一个逻辑定义: 不是"$z$ 无限接近 $z_0$ 时 $f(z)$ 无限接近 $A$", 而是"对任意 $\varepsilon>0$, 存在 $\delta>0$, 使得……". 这两个不起眼的量词 "任意" 与 "存在", 把"无限接近"这种直觉性说法, 变成了可以被机械检验的精确陈述.

轶事 柯西一生写下近 800 篇论文, 产量之大令同代人震惊. 但更值得注意的是他的"较真": 在讨论 $\lim\limits_{z\to z_0} f(z)$ 时, 他刻意把 $z_0$ 点本身排除在邻域之外 (即用去心邻域) —— 因为他意识到, 极限讨论的是"趋近的过程", 与"那一点上到底有没有值、值是多少"无关. 今天课本里"去心邻域"这个细节, 正是一位数学家在逻辑严密性上不肯将就的结果.
魏
魏尔斯特拉斯 (Karl Weierstrass, 1815 — 1897)
德国数学家 · "现代分析之父" · 处处连续处处不可导函数的构造者

如果说柯西搭起了严格化的框架, 魏尔斯特拉斯则把这个框架钉到了最后一道钉子上. 他系统地把 $\varepsilon$-$\delta$ 语言整理成今天课本中的形式, 并证明了"闭区间上连续函数必有界、必取到最值"这类我们现在习以为常的定理.

本节 4.2 中"在闭曲线或包括端点的曲线上连续的函数必在曲线上有界"这一结论, 正是这个思想在复平面上的对应版本 —— 它也是后面积分存在性的根基.

震撼学界的一击 1872 年, 魏尔斯特拉斯在柏林科学院宣读了一个构造: 一条处处连续、却处处不可导的曲线. 在此之前, 几乎所有数学家都凭直觉相信"连续曲线除了个别点外应当都是光滑的" —— 画图时的手感也确实如此. 这个反例直接击穿了直觉的边界, 让人们认识到: 几何直觉必须接受逻辑的检验. 它也解释了本节为什么要如此严苛地定义"光滑曲线" ($z'(t) \ne 0$) —— 若不加这个条件, "连续"与"光滑"会被混为一谈.
数学家的自白
"一个数学家若是不能把自己的想法清楚地向他人说明, 那这个想法大概还没有真正成熟." —— 柯西式的信条: 精确的表达不是为了炫耀严格, 而是为了让真理可以被传递、被检验、被继承. —— 关于"严谨"为何是一种责任
6.2 复变函数中的哲学思想
局部与整体

从"每个点"到"整个区域"

"连续"是一个局部概念 —— 它在每一点上被定义; 而"在区域 $D$ 内连续"却是一个整体陈述. 由局部性质逐点成立, 推广到整体性质处处成立, 这是典型的"由点及面"的认识路径.

反过来, "有界性" "单连通性"则是彻头彻尾的整体性质 —— 你无法只看一个点就判断它是否成立.

局部: $\forall z_0\in D,\ \lim\limits_{z\to z_0}f(z)=f(z_0)$
整体: $f$ 于 $D$ 上连续
逼近与极限

用"有限"把握"无限"

$\varepsilon$-$\delta$ 语言的精髓, 在于用有限的两个正数 ($\varepsilon$ 与 $\delta$) 来描述一个无限逼近的过程. 人类无法真正"走完"无限, 但可以用"对任意的 $\varepsilon$ 都能找到相应的 $\delta$"这种全称命题, 一举把无限过程固化为有限陈述.

这是数学最富智慧的一步: 不逃避无限, 而是给无限立法.

$\forall\varepsilon>0,\ \exists\delta>0:$
$0<|z-z_0|<\delta$
$\Rightarrow\ |f(z)-A|<\varepsilon$
对立统一

连续与间断互为前提

没有"间断", 就无法定义"连续"; 没有"边界", "区域"便无从谈起. 本节中"区域"由开集加上边界共同构成, 这两个互相排斥的对象 (开 vs 闭) 合在一起才给出完整的图景 —— 这正是矛盾双方相互规定的辩证法.

同样, "单连通"与"多连通"的区分也依赖于"洞"这一否定的存在.

区域 $D$ (开) + 边界 $\partial D$ = 闭域 $\overline{D}$
量变到质变

张角翻倍: 从 $w=z$ 到 $w=z^n$

$w = z$ 处处保角; 但一旦乘幂次数 $n \ge 2$, 原点处的角放大倍数就变成了 $n$ —— 保角性在此点量变到质变地失效了. 一个点的特殊, 却要求整套理论为之调整 (这正是后来引入"共形映射在临界点需单独讨论"的原因).

$\arg(z^n) = n\arg z$
$\Rightarrow\ \text{角放大 } n \text{ 倍}$
普遍联系

复变与实变的一一对应

$w = f(z)$ 与一对二元实函数 $u(x,y), v(x,y)$ 的对应, 是联系观点的绝佳例证: 两个看似分立的领域, 通过"实部""虚部"这条纽带被牢牢绑在一起. 复变的难题, 可以拆成两个实变难题; 反之, 实变的结果也能拼回复变.

$f(z) = u(x,y) + \mathrm{i}v(x,y)$
$\longleftrightarrow\ (u,\ v)$
实践检验

反例的力量

"沿两条路径得到不同值, 即可断定极限不存在" —— 这把"证明不存在"这样一个否定性命题, 化为了一个可以动手操作的构造性检验.

数学并不只依靠正面论证前进; 反例是更锋利的武器. 魏尔斯特拉斯那条处处不可导的连续曲线, 就是反例推动学科转向的典范.

路径 1: $\theta=0 \Rightarrow f\to 1$; 路径 2: $\theta=\tfrac{\pi}{2}\Rightarrow f\to -1$ ⇒ 极限不存在

6.5 课堂思辨
思辨题 1
本节说"区域 = 连通的开集". 如果把"连通"这一条删掉, 会剩下什么? 这样的点集在数学上还有用吗?
请结合"引例"思考: 为什么偏偏要求"开"又要求"连通"?
【参考思路】
删掉"连通"后剩下"开集". 开集是拓扑学的基本对象, 当然极其重要.
但在复分析中, 我们常常需要一个"整体上可以互相走到"的讨论场所 —— 因为在这样的场所里, 函数在一个点的局部行为可以通过路径延续到整个场所, 这正是"解析延拓"与"唯一性定理"的前提.
若区域不连通 (例如两个相距很远的圆盘), 函数在一个圆盘上的信息无法传递到另一个圆盘, 讨论就割裂了.
至于"开", 是为了让每一个点都拥有一个完整的邻域, 从而"极限""导数"这些依赖邻域的运算才能顺畅进行.
思辨题 2
"$f(z)$ 在 $z_0$ 处有极限"与"$f(z)$ 在 $z_0$ 处连续"相比, 缺少了什么? 请各举一个例子说明二者的差别, 并思考: 为什么教材要特意强调"去心邻域"?
【参考思路】
连续 = 极限存在 + 该点有定义 + 两者相等. 有极限只是其中第一项.
例 1 (有极限但不连续): $f(z) = \frac{z^2}{z}$ 在 $z \ne 0$ 处等于 $z$, 于是 $z\to 0$ 时极限为 $0$; 但 $f(0)$ 无定义, 故不连续. 这是"可去间断点".
例 2 (有定义有极限但不等): 定义 $f(0)=5$, 而当 $z\ne 0$ 时 $f(z)=z$. 此时 $\lim\limits_{z\to 0} f = 0 \ne 5 = f(0)$, 仍不连续.
为何强调"去心": 因为极限刻画的是"趋近的过程", 与"目标点本身的状态"无关. 用去心邻域, 就把这个意图写进了定义里. 这也保证了极限概念即使在该点无定义时依然可用 —— 而"连续"恰恰需要两者一致, 于是"极限"成了比"连续"更基本的概念.
思辨题 3
魏尔斯特拉斯构造出"处处连续却处处不可导"的函数后, 数学家们不得不重新审视自己的直觉. 请思考: 直觉在数学研究中是财富还是包袱?
结合本节的"简单曲线""光滑曲线"定义谈谈你的看法.
【参考思路】
直觉两者都是, 关键在如何定位它.
作为财富: 数学发现几乎都始于直觉 —— 柯西、黎曼都先在头脑中"看见"了图形与运动, 才去寻找严格表述. 本节"邻域 = 圆盘""区域 = 平面上的一块地方"这类直观图像, 是理解抽象定义不可缺少的脚手架.
作为包袱: 一旦把直觉当成结论, 就会出错. "连续曲线应当基本光滑"是极其自然的直觉, 却在 1872 年被反例推翻.
本节的启示: 教材之所以把"简单曲线"严格定义为"没有重点", 把"光滑"定义为"$z'(t)\ne 0$", 正是为了把直觉中想说却说不清的东西钉死. 定义之后, 直觉仍可用于猜测方向, 但结论必须回到定义去验证. 也许最恰当的定位是: 直觉负责发现, 逻辑负责确认.
思辨题 4
刘徽的"割圆术"(用正多边形逼近圆) 与本节 $\varepsilon$-$\delta$ 极限语言, 一个在公元三世纪的中国, 一个在十九世纪的欧洲. 请思考: 二者"相通"在何处? "不同"又在何处? 这种不同说明了什么?
【参考思路】
相通: 二者都在处理"无限逼近" —— 刘徽"割之又割, 以至于不可割"描述的是一个取极限的过程; $\varepsilon$-$\delta$ 描述的也是"要多近有多近". 更重要的是, 二者的实践取向一致: 都是为了得到一个可以放心使用的确定结果 (圆面积 / 极限值).
不同: 刘徽的方法是构造性、算法性的 —— 它给出可计算的近似序列, 结论伴随可操作的误差估计, 可以直接用来算 $\pi$. 而 $\varepsilon$-$\delta$ 是存在性、逻辑性的 —— 它不提供算法, 只保证"这样的 $\delta$ 存在".
说明什么: 这体现了东西方数学传统的不同侧重 —— 中国传统数学长于算法与实用, 希腊—欧洲传统长于公理与演绎. 二者并无高下, 而是互补. 现代数学恰恰是两条路线的汇流: 既要有构造性算法 (数值分析、计算数学), 也要有存在性理论 (实分析、复分析). 今天中国数学的追求, 正是同时在这两条路上走到世界前列.
思辨题 5
本节的"映射"观点要求我们同时想象两个复平面. 请思考: 这种"在两个空间之间建立对应"的思维方式, 在数学之外还有哪些体现? 它对我们的学习与工作有何启发?
【参考思路】
"映射"的本质是用一个已知的世界去理解一个未知的世界.
数学之外: 地图就是地球到平面的映射; 翻译是一种语言到另一种语言的映射; 经济模型用数学结构映射现实市场; 计算机中的数据结构转换 (如哈希表) 也是一种映射.
学习启发: 遇到陌生概念时, 主动问"它是否能建立与我已知事物的对应". 例如本节把复变函数对应成"一对二元实函数", 立刻就让抽象的 $f(z)$ 变得可计算 —— 这就是寻找"已知识域中的同构物".
工作启发: 跨领域合作之所以有效, 正是因为不同专业之间存在着"映射"关系. 数学家把流体问题翻译成复变问题, 医生把症状翻译成病理机制, 工程师把需求翻译成技术指标 —— 善于建立并利用这些映射的人, 往往能解决别人解决不了的问题.
更高一层的体会: 数学训练的真正价值, 或许不在于记住多少公式, 而在于培养这种"主动寻找结构对应"的思维习惯.

本节思政小结
