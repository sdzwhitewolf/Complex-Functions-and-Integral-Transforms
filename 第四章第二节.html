泰勒展开定理 · 直接法与间接法 · 常用展开式

学习目标: 1. 掌握泰勒展开定理的条件、结论与系数公式, 理解收敛半径与最近边界点的关系; 2. 理解"函数解析 ⟺ 可展开为幂级数"这一解析函数的本质刻画; 3. 理解解析函数幂级数展开的唯一性; 4. 掌握直接展开法 ($\mathrm{e}^z$, $\sin z$, $\cos z$ 等) 与间接展开法 (逐项求导、逐项积分、代换); 5. 熟记 $\frac{1}{1-z}$、$\ln(1+z)$、$\mathrm{e}^z$、$\sin z$、$\cos z$ 等常用展开式; 6. 借助交互直观感受"多项式部分和逼近解析函数"与"奇点决定收敛半径".
1.1 泰勒展开定理
定理 2.1 (泰勒展开定理)

设 $f(z)$ 在区域 $D$ 内解析, $z_0$ 为 $D$ 内的一点, $d$ 为 $z_0$ 到 $D$ 的边界上各点的最短距离, 则当 $|z - z_0| < d$ 时,

$f(z) = \sum\limits_{n=0}^{\infty} c_n (z - z_0)^n$,  其中 $c_n = \frac{1}{2\pi \mathrm{i}} \oint_{K} \frac{f(\zeta)}{(\zeta - z_0)^{n+1}}\, \mathrm{d}\zeta = \frac{f^{(n)}(z_0)}{n!}$   ($n = 0, 1, 2, \cdots$)

上式称为 $f(z)$ 在 $z_0$ 的泰勒展开式, 其右端的级数称为泰勒级数.

证明思路 (以 $z_0$ 为心、$r < d$ 为半径)
  • 第一步 以 $z_0$ 为心、适当长 $r$ 为半径作正向圆周 $K: |\zeta - z_0| = r$, 则 $K$ 及其内部含于 $D$. 设 $z$ 为 $K$ 内任一点, 由柯西积分公式 $$f(z) = \frac{1}{2\pi \mathrm{i}} \oint_K \frac{f(\zeta)}{\zeta - z}\, \mathrm{d}\zeta$$
  • 第二步 由于 $\left| \frac{z - z_0}{\zeta - z_0} \right| = \frac{|z - z_0|}{r} < 1$, 有几何级数展开 $$\frac{1}{\zeta - z} = \frac{1}{(\zeta - z_0) - (z - z_0)} = \frac{1}{\zeta - z_0} \left[ 1 + \frac{z-z_0}{\zeta-z_0} + \cdots + \frac{(z-z_0)^n}{(\zeta-z_0)^n} + \cdots \right]$$
  • 第三步 将上式代入柯西积分公式, 逐项积分并利用高阶导数公式 $$\oint_K \frac{f(\zeta)}{(\zeta - z_0)^{n+1}}\, \mathrm{d}\zeta = \frac{2\pi \mathrm{i}}{n!} f^{(n)}(z_0)$$ 得 $f(z) = \sum\limits_{n=0}^{\infty} \frac{f^{(n)}(z_0)}{n!} (z - z_0)^n$ 与余项 $R_N(z)$ 之差.
  • 第四步 由于 $f(z)$ 在 $D$ 内解析, $f(\zeta)$ 在 $K$ 上连续, 于是 $f(\zeta)$ 在 $K$ 上有界: $|f(\zeta)| \le M$, 从而 $$|R_N(z)| \le \left| \frac{1}{2\pi \mathrm{i}} \oint_K \frac{f(\zeta)\,\mathrm{d}\zeta}{(\zeta - z)^{N+1} (\zeta - z_0)} \right| \cdot r \le \frac{M \cdot q^{N+1}}{1 - q} \cdot \frac{1}{r - |z - z_0|} \to 0 \quad (N \to \infty)$$ 其中 $q = \frac{|z - z_0|}{r} < 1$. 故泰勒展开式成立. $\blacksquare$
1.2 展开的条件与收敛半径
注: (1) 若 $f(z)$ 在 $z_0$ 解析, 且 $z_0$ 是 $f(z)$ 在 $D$ 内距离最近的一个边界点, 则 $f(z)$ 在 $z_0$ 的泰勒展开式成立的圆域半径为 $R = d$.
(2) 函数解析的充要条件是它在该点的邻域内可以展开为幂级数 —— 这个性质从级数角度反映了解析函数的本质.
思想史 · 泰勒级数为何"迟到"了一百多年? 1715 年, 英国数学家泰勒 (B. Taylor, 1685—1731) 在《正的和反的增量方法》中写出了这条公式 —— 比柯西建立"收敛"概念早了整整一百年.
但泰勒当年既没有讨论收敛性, 也没有要求函数解析. 在他看来, 这只是"用导数把函数拼出来"的一种形式技巧, 能不能用、在多大范围内能用, 统统不管. 十八世纪的数学家 (包括欧拉) 大量使用这类级数, 并因此得出过不少错误结论.
真正把这条公式变成"定理"的是柯西与魏尔斯特拉斯: 他们补上了两个关键条件 —— ① 函数必须在 $z_0$ 的邻域内解析; ② 展开只在 $z_0$ 到最近奇点的距离 $d$ 之内成立. 定理 2.1 的"$R = d$"正是这一点的精确表述.
一句话: 泰勒发现了公式, 柯西与魏尔斯特拉斯赋予了它生命. 一个数学结论的价值, 不仅在于它"写出来好看", 更在于它"在什么条件下成立" —— 这也是本课程反复强调"解析"二字的原因.
展开式的唯一性

问题: 利用泰勒级数可以将函数展开为幂级数, 展开式是否唯一?

答: 唯一. 假设 $f(z)$ 在 $z_0$ 处展开为幂级数 $f(z) = \sum\limits_{n=0}^{\infty} a_n (z-z_0)^n$, 逐次求导并令 $z = z_0$:

$f(z_0) = a_0, \quad f'(z_0) = a_1, \quad f''(z_0) = 2! \, a_2, \ \cdots, \quad f^{(k)}(z_0) = k! \, a_k$

即 $a_k = \frac{f^{(k)}(z_0)}{k!}$ —— 与泰勒系数完全一致. 故解析函数展开成的幂级数就是泰勒级数, 不存在第二种系数.

交互 · 奇点决定收敛半径 拖动 $z_0$ 观察可展范围

泰勒展开定理说: 展开成立的范围, 以 $z_0$ 到最近边界点/奇点的距离 $d$ 为半径. 拖动蓝点 $z_0$: 绿色圆盘 (半径 $d$) 就是泰勒级数保证收敛的范围; $z_0$ 越靠近红色 ✕ (奇点), 圆盘越小.
2.1 直接展开法
直接展开法

由泰勒展开定理计算系数 $c_n = \frac{f^{(n)}(z_0)}{n!}$, 然后将函数展成幂级数 $f(z) = \sum\limits_{n=0}^{\infty} \frac{f^{(n)}(z_0)}{n!}(z - z_0)^n$.

适用于导数规律明显的函数.

直接法: 三个最基本的展开式
例 2.1  将 $f(z) = \mathrm{e}^z$ 在 $z_0 = 0$ 处展成幂级数.

【解】由于 $f^{(n)}(z) = \mathrm{e}^z$, 从而 $f^{(n)}(0) = \mathrm{e}^0 = 1$ ($n = 0, 1, 2, \cdots$), 故

$\mathrm{e}^z = \sum\limits_{n=0}^{\infty} \frac{z^n}{n!} = 1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \cdots + \frac{z^n}{n!} + \cdots$

因为 $\mathrm{e}^z$ 在复平面内处处解析, 故幂级数收敛半径 $R = +\infty$.

用直接展开法可得 $\sin z$ 和 $\cos z$ 在 $z_0 = 0$ 的泰勒展开式 ($R = +\infty$): $$\sin z = \sum_{n=0}^{\infty} \frac{(-1)^n z^{2n+1}}{(2n+1)!} = z - \frac{z^3}{3!} + \frac{z^5}{5!} - \cdots$$ $$\cos z = \sum_{n=0}^{\infty} \frac{(-1)^n z^{2n}}{(2n)!} = 1 - \frac{z^2}{2!} + \frac{z^4}{4!} - \cdots$$
2.2 系数与常用展开式
五个必背母式 (间接法的"原子")
母式展开式收敛范围
$\frac{1}{1-z}$$\sum\limits_{n=0}^{\infty} z^n = 1 + z + z^2 + \cdots$$|z| < 1$
$\mathrm{e}^z$$\sum\limits_{n=0}^{\infty} \frac{z^n}{n!} = 1 + z + \frac{z^2}{2!} + \cdots$$|z| < +\infty$
$\sin z$$\sum\limits_{n=0}^{\infty} \frac{(-1)^n z^{2n+1}}{(2n+1)!} = z - \frac{z^3}{3!} + \cdots$$|z| < +\infty$
$\cos z$$\sum\limits_{n=0}^{\infty} \frac{(-1)^n z^{2n}}{(2n)!} = 1 - \frac{z^2}{2!} + \cdots$$|z| < +\infty$
$\ln(1+z)$$\sum\limits_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} z^n = z - \frac{z^2}{2} + \frac{z^3}{3} - \cdots$$|z| < 1$
小结: 第二节的绝大多数例题, 本质都是把待展开的函数化归到上面五个式子之一. 熟记这五个母式 + 三板斧, 泰勒展开题基本可以"一眼定位".

3.1 间接展开法
间接展开法

借助于一些已知函数的展开式, 结合解析函数的性质、幂级数运算性质 (逐项求导、积分等) 和复合运算 (代换等), 求函数的泰勒展开式.

最常用、最高效的方法.

间接法: 两个最常用的母公式
(1) 几何级数 ($|z| < 1$): $$\frac{1}{1-z} = \sum_{n=0}^{\infty} z^n = 1 + z + z^2 + \cdots$$ (2) 对数函数的主支 ($|z| < 1$), 由逐项积分得到: $$\ln(1+z) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} z^n = z - \frac{z^2}{2} + \frac{z^3}{3} - \cdots$$
间接法三板斧: ① 代换 — 把 $z$ 换成 $-z,\ z^2,\ \frac{z}{2}$ 等; ② 逐项求导 / 逐项积分 — 在收敛圆内合法 (定理 1.6); ③ 部分分式分解 — 处理有理函数. 每一步都要重新确认收敛范围!
3.2 派生展开式一览

交互 · 间接法派生树 切换手段看派生

所有常用的幂级数, 都可以从一条母式 $\frac{1}{1-z} = \sum\limits_{n=0}^{\infty} z^n$ 派生出来. 点击左侧按钮, 观察不同的间接法手段如何"长"出新的展开式 —— 派生之后, 收敛范围必须重新确认.
4.1 例题精讲
例 2.2  将函数 $\frac{1}{(1-z)^2}$ 展开为 $z$ 的幂级数.

【解】由于 $\frac{1}{1-z}$ 在单位圆周 $|z| = 1$ 上有一个奇点 $z = 1$, 而在 $|z| < 1$ 内处处解析, 所以在 $|z| < 1$ 内可展成幂级数. 利用已知展开式

$\frac{1}{1-z} = 1 + z + z^2 + \cdots \quad (|z| < 1)$

对上式两端逐项求导, 得

$\frac{1}{(1-z)^2} = 1 + 2z + 3z^2 + \cdots + n z^{n-1} + \cdots = \sum\limits_{n=1}^{\infty} n\, z^{n-1} \quad (|z| < 1)$

要点: 收敛范围由"最近奇点"决定, 与逐项求导无关 —— 求导不改变收敛半径.

例 2.3  求对数函数的主值 $\ln(1+z)$ 在 $z_0 = 0$ 处的泰勒展开式.

【解】$\ln(1+z)$ 在从 $z = -1$ 向左沿负实轴剪开的平面内是解析的, 因为 $z = -1$ 是距离原点最近的奇点, 所以它在 $|z| < 1$ 内可以展成 $z$ 的幂级数.

在单位圆内任取从 $0$ 到 $z$ 的积分路线 $C$, 将展开式 $$\frac{1}{1+z} = \sum_{n=0}^{\infty} (-1)^n z^n = 1 - z + z^2 - \cdots \quad (|z| < 1)$$ 两端沿 $C$ 逐项积分, 得

$\ln(1+z) = \sum\limits_{n=0}^{\infty} \frac{(-1)^n}{n+1} z^{n+1} = z - \frac{z^2}{2} + \frac{z^3}{3} - \cdots \quad (|z| < 1)$

要点: 逐项积分在收敛圆内合法; 积分下限给出常数项 $c_0 = \ln(1) = 0$.

4.2 综合技巧
拓展例题  将 $\frac{1}{(1+z)(1-z)}$ 与 $\frac{z}{(1+z)^2}$ 展开为 $z$ 的幂级数 (综合训练).

【解】(1) $\frac{1}{(1+z)(1-z)} = \frac{1}{1-z^2} = \sum\limits_{n=0}^{\infty} z^{2n} = 1 + z^2 + z^4 + \cdots$   ($|z^2| < 1$ 即 $|z| < 1$).

(2) 对 $\frac{1}{1+z} = \sum\limits_{n=0}^{\infty} (-1)^n z^n$ 两端逐项求导: $-\frac{1}{(1+z)^2} = \sum\limits_{n=1}^{\infty} (-1)^n n z^{n-1}$, 故 $$\frac{z}{(1+z)^2} = \sum_{n=0}^{\infty} (-1)^n (n+1) z^{n+1} = z - 2z^2 + 3z^3 - \cdots \quad (|z| < 1)$$

不唯一, 系数可任意 唯一, 系数必为 $f^{(n)}(z_0)/n!$ 仅在圆内唯一 与展开方法有关

整个复平面 $|z| < 1$ $0 < |z| < 1$ $|z| > 1$

$1/4!$ $1/4!$ 且符号为 $+$ $-1/4!$ $0$

$1$ $2$ $+\infty$ $1/2$
$f$ 唯一的奇点是 $z=2$, 到 $z_0=0$ 的距离为 $2$, 故 $R=2$.
8. 用间接法展开 $f(z) = z^{2}\mathrm{e}^{z}$, 其 $z^{5}$ 项系数为?
$1/5!$ $1/3!$ $1/2!$ $0$

然而历史把这项发现冠上了他的名字. 这背后既有某种幸运, 也提醒我们一个耐人寻味的问题: 一项发现的价值, 究竟由"谁先想到"决定, 还是由"谁把它说清楚、写下来、传出去"决定?

1身世: 英国绅士数学家

泰勒出生于英格兰肯特郡一个富裕的家庭, 父亲是一位乡绅. 他自幼受到良好教育, 1701 年进入剑桥大学圣约翰学院, 1709 年获得法学博士(LL.D.). 他曾在皇家学会担任秘书(1714—1718), 是牛顿与哈雷的同时代人, 也与当时的英国学界交往甚密.

与阿贝尔、洛朗这些"寒门天才"不同, 泰勒一生衣食无忧, 却有另一重不幸: 他的第一任妻子在婚后不久去世, 第二任妻子也在生育后离世. 家庭的接连变故让他心灰意冷, 晚年一度放弃数学研究, 转向宗教与艺术问题, 45 岁便去世.

2核心贡献: 用无穷多项式"造"出任意函数

1715 年, 泰勒在《增量法》(Methodus Incrementorum Directa et Inversa) 中给出了这个展开式, 并把"增量"(即微分)与"无穷级数"这两个观念结合了起来 —— 这在当时是一项创举.

但必须说明: 在泰勒之前, 已经有很多人触及过这个想法. 苏格兰数学家格雷果里(James Gregory)在 1671 年前后就用类似级数算过 $\arctan$ 等的展开; 莱布尼茨、约翰·伯努利也都沿这条思路做过工作. 泰勒的贡献在于系统、清晰地写出了它. 也正因为如此, 后世才把这项荣誉给了他的名字.

3一个遗憾: 他没有管收敛

泰勒在书中完全没有讨论这个级数"什么时候收敛"、"收敛到原函数吗". 他只是把它当作一个形式上的展开来用 —— 这在他那个年代是常态. 直到一个多世纪后, 柯西、阿贝尔、魏尔斯特拉斯才一步步把它变成能被信任的定理.

今天我们写泰勒展开时, 第一步就是"注明收敛范围"; 求收敛半径时还要看"离最近奇点的距离". 这些要求, 都是泰勒之后一百多年才补上的. 这也正说明: 数学的进步常常是"先有工具, 后有标准".

轶事泰勒还研究过一个与数学无关的问题: 什么是"更好的透视画法"? 他在《直线透视》(Linear Perspective, 1715) 中用几何原理给出了严格的透视法则, 被誉为西方绘画透视理论的奠基之作之一. 同一个用无穷级数描述函数的人, 也用同样的"几何眼光"去描述世界如何被看见 —— 数学与艺术在他身上并不冲突.
◈ 从泰勒到我们的课堂
今日课堂上一句"把 $f(z)$ 在 $z_0$ 处展成幂级数", 背后其实是三百年的层层追问:
泰勒: 能不能写成 $\sum a_n (z-z_0)^n$ ?
柯西: 什么时候它收敛? 收敛到谁?
魏尔斯特拉斯: 收敛域内, 它和原函数是不是"同一个东西"? —— 每一个看似"顺理成章"的公式, 都有一段被反复追问的历史. 知道这一点, 公式就活了.
6.2 数学家故事 · 欧拉: 失明后仍在运算的巨人
欧
莱昂哈德·欧拉 (Leonhard Euler, 1707—1783)
瑞士数学家、物理学家 · 圣彼得堡科学院与柏林科学院院士 · 史上最高产的数学家 · 全字母常数 $e$ 的命名者

如果要在数学史上选出"最多产"的人, 答案几乎没有争议 —— 欧拉. 他一生发表著作与论文超过 800 篇(部), 全集出版至今仍未完全整理完毕. 后来的数学家开玩笑说: "欧拉写论文就像别人写信一样容易."

本节最常用的几个"母展开式" —— $\mathrm{e}^z$, $\sin z$, $\cos z$, $\frac{1}{1-z}$, $\ln(1+z)$ —— 几乎都是欧拉亲手处理定型的. 而 $\mathrm{e}^{\mathrm{i}\pi} + 1 = 0$ 这一被反复评为"最美"的公式, 走的正是无穷级数这条路.

1身世: 牧师的儿子与伯努利的学生

欧拉出生于瑞士巴塞尔, 父亲是一名牧师. 他听从父亲的安排进大学读神学, 却忍不住去听约翰·伯努利的数学课. 伯努利很快发现这个安静的孩子有着惊人的计算力, 于是每周六下午单独给他答疑 —— 这成了欧拉一生中最重要的"私人辅导".

20 岁时, 欧拉受聘前往俄国圣彼得堡科学院. 彼得的严寒与动乱没有动摇他, 他在那里工作了 14 年; 后来应腓特烈大帝之邀前往柏林科学院(1741—1766), 晚年又回到圣彼得堡, 直到生命的最后一刻.

2核心贡献: 让级数成为"可以放心使用的工具"

1748 年, 欧拉出版《无穷分析引论》(Introductio in analysin infinitorum), 这是分析学史上的里程碑. 他把函数、级数、指数与三角函数放进同一个框架: 由幂级数定义 $\mathrm{e}^z$, 由幂级数定义 $\sin z$ 与 $\cos z$, 二者相加即得

欧拉公式
$\mathrm{e}^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta$, 取 $\theta=\pi$ 即得 $\mathrm{e}^{\mathrm{i}\pi} + 1 = 0$.

他还用级数求出了 $\sum \frac{1}{n^2} = \frac{\pi^2}{6}$ —— 这个问题("巴塞尔问题")曾难倒伯努利家族整整一代人, 欧拉用级数展开一举解决. 更惊人的是, 他还算出了 $\sum \frac{1}{n^4}$, $\sum \frac{1}{n^6}$ 等一大批和式.

为什么本节要特别提欧拉? 因为我们求泰勒展开用的"母式"和"间接法", 本质上是欧拉建立起来的技术体系. 你写下的每一行 $\frac{1}{1-z} = \sum z^n$, 都踩在欧拉铺的路上.

3失明之后: 心算完成一半的著作

1735 年, 欧拉因长期过度工作导致右眼失明; 1766 年, 左眼也失去视力, 他完全失明. 但接下来的十七年, 竟是他创作力最旺盛的时期之一.

他凭借惊人的记忆与心算能力继续工作: 让人记录他口述的论文, 在脑中完成复杂的级数与积分运算. 他著名的《代数学引论》《积分学原理》等著作, 有相当一部分就是在失明后完成的. 他的助手曾说: 欧拉可以在脑中背诵整页的《埃涅阿斯纪》, 并记得每一版的印刷差异.

4晚境: 在纸页与烟斗之间离去

1783 年 9 月 18 日, 76 岁的欧拉在一次家庭聚会上与人讨论新发现的天王星轨道, 并随手在纸上画着计算. 之后他停下来喝了一口茶, 抱起孙子玩耍, 忽然说了一句"我要死了", 随后因脑溢血去世 —— 算题算到了生命的最后一刻.

法国数学家孔多塞为他写下墓志铭般的评语: "欧拉停止了计算, 也就停止了生活."

轶事欧拉在双目失明后仍然坚持推演级数. 当他宣布 $\mathrm{e}^{\mathrm{i}\pi} + 1 = 0$ 以及众多级数和的结论时, 同行先是质疑(一个盲人怎么能算出这么复杂的和?), 继而验证, 最后叹服. 科学不相信权威, 只相信可验证的严谨 —— 这也正是我们做每一步泰勒展开都要"注明收敛范围、检查条件"的原因.
◈ 欧拉的治学心法
他在困难面前留下的态度, 至今仍是数学工作者的座右铭:
"因为世界上的事务, 都要服从于某种最大或最小的规律, 所以毫无疑问, 每一个数学问题都可以用某种极大或极小的方法来求解."
而面对"无法继续计算"的处境, 他的做法是:
"我计算, 一直计算, 直到我看见了光." —— 天才不是不需要努力, 而是把努力变成了一种本能. 这是欧拉留给"勤奋"二字最有力的注解.
6.3 数学家故事 · 魏尔斯特拉斯: 让泰勒级数"名副其实"的人
魏
卡尔·魏尔斯特拉斯 (Karl Weierstrass, 1815—1897)
德国数学家 · 柏林大学教授 · "现代分析之父" · $\varepsilon$-$\delta$ 语言的创立者 · 解析函数论的奠基人

本书第四章的几个关键概念 —— 收敛半径、幂级数的收敛域、以及泰勒级数与解析函数的等价性 —— 背后站着的正是魏尔斯特拉斯. 他是把 19 世纪的分析从"直觉"彻底带向"严格"的人.

他证明了一件极其重要的事: 在复平面上, "解析"与"可以展成局部幂级数"是同一件事. 这句话把泰勒级数从"计算技巧"提升为复分析的定义性工具.

1身世: 大器晚成的中学教师

魏尔斯特拉斯生于德国威斯特法伦一个天主教家庭. 他的父亲希望他做公务员, 于是把他送进波恩大学读法律与财政 —— 但他几乎不听课, 把时间花在击剑、喝酒与自学数学上. 结果是: 他没拿到学位就离开了大学.

更艰难的是, 此后他当了 14 年中学教师. 他教过数学、物理、德文、地理甚至体育, 白天上课、批作业, 只能在深夜研究数学. 正是这段被后人称为"深夜的数学"的岁月里, 他完成了关于阿贝尔函数与解析函数论的最重要工作.

2核心贡献: $\varepsilon$-$\delta$ 语言与解析函数论

魏尔斯特拉斯最大的功绩, 是把柯西等人还留有"无限趋近"模糊性的语言, 改造成今天教科书里的 $\varepsilon$-$\delta$ 定义: "对任意 $\varepsilon > 0$, 存在 $\delta > 0$, 使得……" 这套语言让极限、连续、收敛第一次有了完全无歧义的表述.

在复分析中, 他提出了以幂级数为基础的解析函数理论: 解析函数就是局部可以展开成收敛幂级数的函数; 两个解析函数若在一个有极限点的集合上相等, 则处处相等(唯一性定理). 本节学到的"泰勒展开唯一"、"系数由导数唯一决定", 正是这套理论的直接推论.

他还发现了著名的魏尔斯特拉斯函数 —— 处处连续但处处不可微的函数, 一举击碎了"连续曲线必然大部分可微"的直觉, 成为数学严格化运动中最有力的"反例武器".

3晚境: 从中学讲台到柏林大学

1854 年, 魏尔斯特拉斯在《克雷勒杂志》上发表了一篇关于阿贝尔函数的论文 —— 署名只是一个"中学教师". 论文立刻震动了数学界, 柯尼斯堡大学很快授予他荣誉博士学位, 柏林大学随即聘任他为教授.

此后他成为柏林学派的核心人物, 培养出柯瓦列夫斯卡娅(人类历史上第一位数学女博士、第一位女教授)、康托尔、施瓦茨等一批杰出学生. 他讲课极其严谨, 一句"我们必须在每一步都问: 这真的成立吗?" 成了柏林学派的风格标志.

轶事魏尔斯特拉斯年轻时把研究成果寄给著名数学家古德曼, 古德曼看后大为赞赏, 称他为"数学的秘密王者". 一个默默无闻的中学教师, 就这样被同行一眼认出. 这段故事常被用来提醒年轻人: 真正的才华藏不住, 但准备好被看见, 同样重要.
⚔ 一次"直觉"与"严格"的对撞
旧直觉的说法: "连续曲线总能画出来, 画得出来的曲线当然至少大部分地方是光滑的." —— 这是 19 世纪以前几乎所有数学家的默认信念.
魏尔斯特拉斯的反例: 1872 年, 他构造出一个处处连续、却处处不可导的函数. 换句话说: 一条"一笔画得出"的曲线, 处处都不光滑, 处处都没有切线.
历史公论: 这个反例让当时的大数学家埃尔米特都感到"惊骇", 称它是"令人厌恶的祸害". 但正是它, 逼着人们放弃"画得出来就光滑"的直觉, 转向严格的 $\varepsilon$-$\delta$ 定义 —— 数学不是关于画图, 而是关于逻辑.
6.4 数学家故事 · 刘徽: 割圆术里的东方极限思想
刘
刘徽 (约 225 — 295)
魏晋时期数学家 · 《九章算术注》与《海岛算经》作者 · 中国古典数学理论的奠基人之一 · 割圆术创立者

当欧洲还在用罗马数字、几何学尚未系统化的时候, 中国已经有一位数学家提出了一套可以操作、可以检验、可以无限精细的逼近方法 —— 割圆术. 它的思想内核, 与今天的"部分和数列趋于极限"完全一致.

刘徽的割圆术与泰勒级数, 相隔一千五百多年、跨越万水千山, 却讲着同一个故事: 用有限去逼近无限, 用可算出的事物去把握算不出的事物.

1身世: 流传甚少的巨人

关于刘徽本人, 史书留下的记载极少 —— 我们甚至不知道他的确切生卒年与生平事迹. 我们只知道他生活于魏晋时期, 是山东一带的学者, 在公元 263 年为《九章算术》作了详尽的注释, 并撰写了《海岛算经》.

但正是这部注释, 让《九章算术》从一本"算法手册"升华为有理论、有证明的数学著作. 他在中国数学史上的地位, 常被比作"东方的欧几里得".

2割圆术: 一次真正的"极限"实践

刘徽从圆内接正六边形出发, 不断把边数加倍 —— 12 边、24 边、48 边…… 随着边数增多, 正多边形面积越来越接近圆面积. 他用正 192 边形算出 $\pi \approx 3.14$, 又算到正 3072 边形, 得到 $\pi \approx 3.1416$.

关键在于他那句名言: "割之弥细, 所失弥少; 割之又割, 以至于不可割, 则与圆周合体而无所失矣." —— 这句话包含了三重深刻的思想: ① 误差可以任意小(所失弥少); ② 这个过程可以无限进行(割之又割); ③ 无限进行的结果是精确相等(与圆周合体). 这就是"部分和数列趋于极限"的东方表达.

3与泰勒级数的对话

把"以多边形逼近圆"换成"以多项式逼近曲线", 割圆术立刻变成了泰勒级数: 多项式是"直线段的推广", 每增加一项就相当于把多边形多切一刀; 余项 $R_N(z)$ 就是"所失"; $N \to \infty$ 时 $R_N \to 0$, 就是"无所失".

两者的差异在于: 刘徽的方法给出了可算的误差估计(他能说出"所失"有多少), 而泰勒级数的一般理论要到柯西、魏尔斯特拉斯才补上余项估计与收敛条件. 从这个角度看, 中国古代数学在"逼近的算法化"这一点上, 并不落后.

6.5 数学中的哲学: 局部、唯一与精度
哲学视角

局部与整体

泰勒展开只用 $z_0$ 一点的各阶导数, 就重构了整个邻域内的函数 —— "见微知著". 而奇点决定收敛半径: 局部的缺陷, 划定了整体的边界.

$R = d$ (到最近奇点的距离): 一个人的"可展开范围", 常常由最近的短板决定.
方法论

唯一性精神

无论直接求导还是间接代换, 最终系数必然相同 —— "条条大路通罗马"的前提是罗马坐标唯一. 数学结果的唯一性, 支撑了科学结论的客观性.

$a_k = \frac{f^{(k)}(z_0)}{k!}$: 方法可以灵活, 标准必须唯一.
量变质变

加一项, 精度升一档

泰勒多项式的每一次"加项", 都让逼近精度提升一阶(误差从 $O(h^N)$ 变为 $O(h^{N+1})$). 这是最典型的"量变引起质变" —— 在数值计算里, 多一项往往就是"能不能用"的分界线.

$|R_N| \le \frac{M\,|z-z_0|^{N+1}}{(N+1)!} \to 0$: 每一项都在为最终的可靠买单.
科学精神

先有工具, 后有标准

泰勒本人从不讨论收敛. 从 1715 到 1870 年代, 人类用了一百五十年才把"什么时候可信"说清楚 —— 这条补课之路由柯西、阿贝尔、魏尔斯特拉斯共同完成.

工具的出现往往领先于它的理论基础 —— 但这不意味着可以跳过严格性.
整体观

解析 = 可展成幂级数

魏尔斯特拉斯的核心洞见: 在复平面上, "在一个邻域内可导"与"可展成收敛幂级数"竟是同一件事. 复分析的全部威力, 都源自这个"看似巧合"的等价性.

$f$ 解析 $\iff$ $f$ 局部等于某个收敛幂级数 —— 这不是定理之外的东西, 而是解析性的定义本身.
家国情怀

精度即实力

从刘徽的 3.14 到祖冲之的 3.1415926, 再到今天芯片仿真需要的十几个有效数字, "逼近精度"的每一步提升都由级数理论支撑.

泰勒余项估计 $|R_N| \to 0$: 把"差不多"变成"差多少可算", 是大国工程的最小语言单位.
6.6 古今对话: 从割圆术到国产大飞机
中国古代的逼近传统
《周髀算经》中已有"周三径一"的粗略说法; 刘徽创割圆术, 把 $\pi$ 算到 $3.1416$; 祖冲之更进一步, 得到 $3.1415926 < \pi < 3.1415927$, 并提出密率 $\frac{355}{113}$ 与约率 $\frac{22}{7}$, 领先世界近千年. 祖冲之的"缀术"虽然失传, 但其精神 —— 用越来越精细的有理逼近去锁定无理数 —— 正是级数逼近思想的中国版本.
中国古代数学在"算法化、实用化、可计算"上有独特优势; 而柯西、魏尔斯特拉斯一脉的工作则补上了"公理化、严格化"这一环. 两种传统合流, 才有了现代科学计算的面貌.
现代回响: 泰勒展开在"大国重器"中的身影
  • 嫦娥探月与北斗导航: 轨道预报需要反复求解非线性微分方程, 其数值解法(如龙格-库塔法)的核心, 正是泰勒展开的截断与误差控制. 少算一项, 轨道就可能偏出几百米.
  • C919 大飞机: 翼型气动力的计算依赖计算流体力学, 网格点上的通量重构几乎都建立在局部多项式逼近之上. "多算一项、误差降一档"直接关系到气动效率与安全余量.
  • 国产 EDA 与芯片仿真: 器件模型的求解需要极高精度, 十几个有效数字的背后, 是对泰勒展开阶数与收敛性的精确控制.
  • 华罗庚与多复变函数论: 华罗庚在"典型域"与"华氏算子"上的工作, 建立在多元幂级数展开的现代推广之上 —— 中国数学家在级数理论的前沿从未缺席.
思政启示: 把"逼近"做到极致
从刘徽割圆到魏尔斯特拉斯的 $\varepsilon$-$\delta$, 从泰勒那个"不管收敛"的形式展开, 到今天卫星轨道与飞机翼型的精密计算 —— 人类花了近两千年, 只为把"逼近"这件事做到可靠.
精度的竞争就是国家的竞争力. 学会"多算一项、把误差说清楚", 不只是做数学题的要求, 更是科技工作者对国家的一份责任.

本节思政小结
一个故事: 泰勒在 1715 年写下了那个展开, 却从未讨论它是否收敛 —— 这个"补课"花了整整一百五十年: 柯西给出收敛判别法, 阿贝尔划出收敛半径, 魏尔斯特拉斯最终证明"解析"与"可展成幂级数"本是一回事; 而在东方, 刘徽早在公元 263 年就用"割之弥细, 所失弥少"道出了同一个思想.
一个道理: 用有限逼近无限, 是人类掌握复杂世界的根本方法. 泰勒展开用"一点的局部信息"刻画整个邻域, 用"加一项"换取"精度升一档" —— 这既是局部与整体的辩证法, 也是量变到质变的生动写照. 而更要紧的是: 一个公式真正的价值, 不取决于它被发现得多早, 而取决于它是否被严谨地说清楚、有多少人真正理解它.
一份责任: 从刘徽的割圆术、祖冲之的密率, 到欧拉失明后仍在推演的级数、魏尔斯特拉斯为分析立下的严格标准, 再到今天嫦娥探月、C919 翼型计算背后沉默的多项式逼近 —— 数学的严格性从来不是"学术洁癖", 而是"大国重器"能否可靠运行的底线. 学会把误差说清楚、把条件写完整, 是我们这一代科技工作者对国家最实在的担当.
