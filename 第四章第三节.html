第四章 第3节 洛朗级数

双边级数与收敛圆环 · 洛朗展开定理 · 圆环域展开与围道积分

学习目标: 1. 理解洛朗级数(双边级数)的定义, 掌握其收敛圆环的结构; 2. 掌握洛朗展开定理的条件、结论与系数公式, 理解展开的唯一性; 3. 掌握洛朗展开的直接法与间接法, 会将函数在指定圆环域内展开; 4. 理解"同一个函数在不同圆环域内的洛朗展开不同"; 5. 会利用洛朗展开式计算沿封闭曲线的积分 ($\oint f\,\mathrm{d}z = 2\pi\mathrm{i}\, c_{-1}$); 6. 借助交互直观感受收敛圆环与"解析部分 / 主要部分"的分工.
1.1 洛朗级数 (双边级数)
形如 $$\sum_{n=-\infty}^{+\infty} c_n (z - z_0)^n = \cdots + c_{-n}(z-z_0)^{-n} + \cdots + c_{-1}(z-z_0)^{-1} + c_0 + c_1(z-z_0) + \cdots + c_n (z-z_0)^n + \cdots$$ 的级数称为洛朗级数, 其中 $c_n$ 及 $c_{-n}$ 是复常数.
当所有负幂项系数 $c_{-n} = 0$ 时, 洛朗级数就是幂级数.
注: 洛朗级数是幂级数的推广.
正幂项部分 (解析部分)

$\sum\limits_{n=0}^{\infty} c_n (z - z_0)^n$

是通常的幂级数: 设其收敛半径为 $R$, 即 $\frac{1}{R} = \lim\limits_{n \to \infty} \sqrt[n]{|c_n|}$, 则它在 $|z - z_0| < R$ 内绝对收敛.

负幂项部分 (主要部分)

$\sum\limits_{n=1}^{\infty} c_{-n} (z - z_0)^{-n}$

令 $\zeta = (z - z_0)^{-1}$ 化为幂级数 $\sum\limits_{n=1}^{\infty} c_{-n} \zeta^n$: 设其收敛半径为 $R_1$, 则负幂部分在 $|\zeta| < R_1$ 即 $|z - z_0| > R_1$ 内绝对收敛.

收敛圆环

当且仅当正幂部分与负幂部分都收敛时, 洛朗级数收敛, 其绝对收敛域为圆环

$R_1 < |z - z_0| < R$    (要求 $R_1 < R$)

若 $R_1 \ge R$, 则级数处处发散. 称该圆环为收敛圆环.

定理 3.1 (洛朗级数的性质)

洛朗级数 $\sum\limits_{n=-\infty}^{+\infty} c_n (z - z_0)^n$ 在其收敛圆环 $R_1 < |z - z_0| < R$ 内, 其和函数解析, 而且可以逐项求导和逐项积分.

注: 正幂项部分称为解析部分; 负幂项部分称为主要部分.

拓展 · 主要部分与孤立奇点的分类
核心思想: 洛朗展开的主要部分 (负幂项) 不只是"一部分", 它精确刻画了函数在 $z_0$ 处的奇性. 根据主要部分含有多少项, 孤立奇点被分成三类 —— 这是洛朗级数最重要的应用之一.
可去奇点

主要部分不含任何负幂项 (即 $c_{-1} = c_{-2} = \cdots = 0$), 洛朗展开退化为泰勒展开.

例: $\frac{\sin z}{z} = 1 - \frac{z^2}{3!} + \cdots$ 在 $z_0 = 0$ 处.

$m$ 阶极点

主要部分只含有限多项, 最低次幂为 $(z-z_0)^{-m}$ ($c_{-m} \ne 0$, 更高负次幂为零).

例: $\frac{1}{z(z-1)^2}$ 在 $z_0 = 1$ 处是 2 阶极点.

本性奇点

主要部分含无穷多项负幂项, 无法用有限项表示.

例: $\mathrm{e}^{1/z} = 1 + \frac1z + \frac{1}{2!z^2} + \cdots$ 在 $z_0 = 0$ 处.

交互 · 孤立奇点分类判定器 点击函数, 看洛朗主部

每个函数在 $z_0$ 处都有一个洛朗展开. 点击按钮切换函数, 观察它的负幂项 (主要部分) 有几个、最高次是多少 —— 据此自动判定奇点类型. 图中上方为负幂项的"项数条", 下方给出判定结论与对照.
三类奇点的判定要点
  1. 可去奇点: $\lim\limits_{z \to z_0} f(z)$ 存在且有限 —— 可以"补定义"让函数在该点解析. 判别法: $\lim\limits_{z\to z_0}(z-z_0)f(z) = 0$.
  2. $m$ 阶极点: $\lim\limits_{z \to z_0} f(z) = \infty$. 判别法: $\lim\limits_{z\to z_0}(z-z_0)^m f(z)$ 存在且非零, 而更低次幂的极限为 $\infty$.
  3. 本性奇点: 既不是可去也不是极点. 其特征极其"狂野" —— 由 皮卡定理, 在本性奇点的任意小邻域内, 函数可以取到除至多一个值以外的一切复数值.

交互 · 收敛圆环 拖动滑块调节 $R_1$ 与 $R$

洛朗级数的收敛范围是一个圆环 $R_1 < |z - z_0| < R$: 内边界由负幂部分决定, 外边界由正幂部分决定. 拖动滑块改变两个半径; 当 $R_1 \ge R$ 时圆环消失 —— 级数处处发散.

交互: 级数展开实验台 —— 系数谱、主部与收敛半径三路对照

2.1 洛朗展开定理
定理 3.2 (洛朗展开定理)

设 $f(z)$ 在圆环域 $R_1 < |z - z_0| < R_2$ 内解析, 则 $f(z)$ 一定能在此圆环域内展开为

$f(z) = \sum\limits_{n=-\infty}^{+\infty} c_n (z - z_0)^n$,  其中 $c_n = \frac{1}{2\pi \mathrm{i}} \oint_{C} \frac{f(\zeta)}{(\zeta - z_0)^{n+1}}\, \mathrm{d}\zeta$   ($n = 0, \pm 1, \pm 2, \cdots$)

这里 $C$ 为此圆环域内围绕 $z_0$ 的任一条正向简单闭曲线.

证明思路
  • 第一步 在圆环域内作正向圆周 $K_1: |\zeta - z_0| = r$ 与 $K_2: |\zeta - z_0| = R$ ($R_1 < r < R < R_2$). 设 $z$ 是圆环域 $r < |z - z_0| < R$ 内任一点, 由复合闭路 (多连通域) 柯西积分公式: $$f(z) = \frac{1}{2\pi \mathrm{i}} \left[ \oint_{K_2} \frac{f(\zeta)}{\zeta - z}\, \mathrm{d}\zeta - \oint_{K_1} \frac{f(\zeta)}{\zeta - z}\, \mathrm{d}\zeta \right]$$
  • 第二步 第一个积分: $z$ 在 $K_2$ 内部, 且 $\left| \frac{z - z_0}{\zeta - z_0} \right| < 1$, 展开为正幂级数 (与泰勒定理证法类似), 系数为 $c_n = \frac{1}{2\pi\mathrm{i}} \oint_{K_2} \frac{f(\zeta)}{(\zeta - z_0)^{n+1}} \mathrm{d}\zeta$.
  • 第三步 第二个积分: $z$ 在 $K_1$ 外部, 由 $\frac{1}{\zeta - z} = -\frac{1}{z - z_0} \cdot \frac{1}{1 - \frac{\zeta - z_0}{z - z_0}}$ 且 $\left| \frac{\zeta - z_0}{z - z_0} \right| < 1$, 展开为负幂级数, 系数为 $c_{-n} = \frac{1}{2\pi\mathrm{i}} \oint_{K_1} f(\zeta)(\zeta - z_0)^{n-1} \mathrm{d}\zeta$.
  • 第四步 由闭路变形定理: 对圆环内围绕 $z_0$ 的任一条正向简单闭曲线 $C$, 上述两式中系数可统一表示为 $$c_n = \frac{1}{2\pi \mathrm{i}} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{n+1}}\, \mathrm{d}\zeta \quad (n = 0, \pm 1, \pm 2, \cdots) \qquad \blacksquare$$
洛朗展开的唯一性

在圆环域 $R_1 < |z - z_0| < R_2$ 内解析的函数 $f(z)$ 的洛朗展开是唯一的.

证明: 假设 $f(z)$ 在此圆环域内另有展开式 $f(z) = \sum\limits_{n=-\infty}^{+\infty} b_n (z - z_0)^n$, 以 $(z - z_0)^{-m-1}$ 乘上式两端, 并沿圆环内正向圆周 $C$ 积分, 利用 $\oint_C (\zeta - z_0)^{n-m-1} \mathrm{d}\zeta = 2\pi\mathrm{i}\, \delta_{nm}$ 得

$b_m = \frac{1}{2\pi \mathrm{i}} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{m+1}}\, \mathrm{d}\zeta = c_m \quad (m = 0, \pm 1, \pm 2, \cdots) \qquad \blacksquare$
重要对比: 洛朗系数公式形式上与泰勒系数公式相同, 但不能写成 $\frac{f^{(n)}(z_0)}{n!}$ —— 因为 $z_0$ 可能是奇点 (如 $\mathrm{e}^{1/z}$ 在 $z_0 = 0$), 且被积函数在圆环内不是处处解析, 高阶导数公式不再适用.
2.2 展开的条件与步骤
（1）直接展开法

利用系数公式 $c_n = \frac{1}{2\pi\mathrm{i}} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{n+1}} \mathrm{d}\zeta$ 计算系数, 然后写出 $f(z) = \sum c_n (z - z_0)^n$. 计算量较大.

（2）间接展开法

根据正、负幂项组成的级数的唯一性, 可用代数运算、代换、求导和积分等方法去展开 —— 实际解题的首选.

3.1 圆环域上的展开
例 3.1  将函数 $f(z) = \mathrm{e}^{z^2}$ 在以 $z_0 = 0$ 为中心的圆环域 $0 < |z| < +\infty$ 内展开成洛朗级数.

【解】(1) 直接法. $c_n = \frac{1}{2\pi\mathrm{i}} \oint_C \frac{\mathrm{e}^{\zeta^2}}{\zeta^{n+1}} \mathrm{d}\zeta$ ($C$ 为绕 $z = 0$ 的任一条正向简单闭曲线).

由于 $\mathrm{e}^{z^2}$ 在复平面内处处解析, 当 $n \le -1$ 时, 被积函数 $\frac{\mathrm{e}^{\zeta^2}}{\zeta^{n+1}}$ 在 $C$ 上及其内部解析, 由高阶导数公式… 知

当 $n = 2k \ge 0$ 时, $c_{2k} = \frac{f^{(2k)}(0)}{(2k)!} = \frac{1}{k!}$; 其余 (奇数下标与负下标) $c_n = 0$. 故 $$\mathrm{e}^{z^2} = 1 + z^2 + \frac{z^4}{2!} + \frac{z^6}{3!} + \cdots \quad (0 < |z| < +\infty)$$ (2) 间接法: 直接利用 $\mathrm{e}^w = \sum \frac{w^n}{n!}$, 令 $w = z^2$ 代入即得同样结果.

3.2 典型例题
例 3.2 (核心例题)  将函数 $f(z) = \frac{1}{(z-1)(z-2)}$ 分别在下列圆环域内展开成洛朗级数.

(1) $0 < |z| < 1$;   (2) $1 < |z| < 2$;   (3) $2 < |z| < +\infty$;   (4) $0 < |z-1| < 1$.

【解】先部分分式分解: $\frac{1}{(z-1)(z-2)} = \frac{1}{z-2} - \frac{1}{z-1}$.

(1) 在 $0 < |z| < 1$ 内, 两个奇点都在圆外, 都按 $|z| < 1$ 展开: $\frac{1}{z-2} = -\frac{1}{2}\cdot\frac{1}{1-z/2} = -\sum\limits_{n=0}^{\infty} \frac{z^n}{2^{n+1}}$,   $\frac{1}{z-1} = -\frac{1}{1-z} = -\sum\limits_{n=0}^{\infty} z^n$. 故 $$f(z) = \sum_{n=0}^{\infty} \left(1 - \frac{1}{2^{n+1}}\right) z^n = 1 + \frac{1}{2}z + \frac{3}{4}z^2 + \frac{7}{8}z^3 + \cdots$$ (此时无负幂项 —— 它就是泰勒展开.)

(2) 在 $1 < |z| < 2$ 内: $\frac{1}{z-1} = \frac{1}{z}\cdot\frac{1}{1 - 1/z} = \frac{1}{z} + \frac{1}{z^2} + \frac{1}{z^3} + \cdots$ (负幂); $\frac{1}{z-2} = -\sum\limits_{n=0}^{\infty} \frac{z^n}{2^{n+1}}$ (正幂). 故 $$f(z) = \sum_{n=0}^{\infty} \frac{1}{z^{n+1}} - \sum_{n=0}^{\infty} \frac{z^n}{2^{n+1}}$$

(3) 在 $2 < |z| < +\infty$ 内, 两个奇点都在圆内, 都按负幂展开: $\frac{1}{z-2} = \frac{1}{z}\cdot\frac{1}{1 - 2/z} = \sum\limits_{n=0}^{\infty} \frac{2^n}{z^{n+1}}$. 故 $$f(z) = \sum_{n=0}^{\infty} \frac{2^n - 1}{z^{n+1}} = \frac{1}{z} + \frac{3}{z^2} + \frac{7}{z^3} + \cdots$$

(4) 在 $0 < |z-1| < 1$ 内 (以 $z_0 = 1$ 为中心): 令 $w = z - 1$, 则 $f = \frac{1}{w(w+1)} = \frac{1}{w} - \frac{1}{1+w}$, 其中 $\frac{1}{1+w} = \sum\limits_{n=0}^{\infty} (-1)^n w^n$. 故 $$f(z) = \frac{1}{z-1} - \sum_{n=0}^{\infty} (-1)^n (z-1)^n$$

要点: 同一个函数, 圆环域不同, 洛朗展开就不同 —— 先画图定域, 再逐个展开.

4.1 利用洛朗展开式计算封闭曲线的积分
方法原理

设 $f(z)$ 在圆环域 $R_1 < |z - z_0| < R_2$ 内解析, 则 $f(z)$ 在此圆环域内展开为 $f(z) = \sum\limits_{n=-\infty}^{+\infty} c_n (z - z_0)^n$, 其中

$c_{-1} = \frac{1}{2\pi \mathrm{i}} \oint_C f(\zeta)\, \mathrm{d}\zeta \quad \Longrightarrow \quad \oint_C f(z)\, \mathrm{d}z = 2\pi \mathrm{i}\, c_{-1}$

这里 $C$ 为圆环域内围绕 $z_0$ 的任一条正向简单闭曲线.

技巧: 沿曲线 $C$ 直接积分困难时, 只要把 $f(z)$ 在 $C$ 所在的圆环域内展开, 取出 $c_{-1}$ 即可 —— 展开即积分.

例 3.3  计算积分 $\oint_{|z|=1} \frac{\mathrm{e}^{1/z}}{z}\, \mathrm{d}z$.

【解】被积函数在圆环域 $0 < |z| < +\infty$ 内解析, 且曲线 $|z| = 1$ 在此圆环内.

利用 $\mathrm{e}^{1/z} = 1 + \frac{1}{z} + \frac{1}{2!\,z^2} + \frac{1}{3!\,z^3} + \cdots$ ($|z| > 0$), 得

$\frac{\mathrm{e}^{1/z}}{z} = \frac{1}{z} + \frac{1}{z^2} + \frac{1}{2!\,z^3} + \cdots \quad \Rightarrow \quad c_{-1} = 1$

由洛朗展开式的计算公式, 取 $C$ 为正向圆周 $|z| = 1$: $$\oint_{|z|=1} \frac{\mathrm{e}^{1/z}}{z}\, \mathrm{d}z = 2\pi \mathrm{i} \cdot c_{-1} = 2\pi \mathrm{i}$$

例 3.4  计算积分 $\oint_{|z|=3} \frac{\mathrm{e}^z}{z(z-2)}\, \mathrm{d}z$.

【解】被积函数 $\frac{\mathrm{e}^z}{z(z-2)}$ 有两个奇点 $z_1 = 0$, $z_2 = 2$, 以 $0$ 为心的解析圆环有两个: $0 < |z| < 2$ 与 $2 < |z| < +\infty$. 曲线 $C$ ($|z| = 3$) 在圆环 $2 < |z| < +\infty$ 内, 故在此圆环内将被积函数展成洛朗级数:

$\frac{\mathrm{e}^z}{z(z-2)} = \frac{\mathrm{e}^z}{z^2} \cdot \frac{1}{1 - 2/z} = \mathrm{e}^z \left( \frac{1}{z^2} + \frac{2}{z^3} + \frac{2^2}{z^4} + \cdots \right) \quad (2 < |z| < +\infty)$

于是 $c_{-1} = \sum\limits_{n=0}^{\infty} \frac{2^n}{(n+1)!} = \frac{1}{2} \sum\limits_{n=0}^{\infty} \frac{2^{n+1}}{(n+1)!} = \frac{1}{2}\left( \mathrm{e}^2 - 1 \right)$, 故

$\oint_{|z|=3} \frac{\mathrm{e}^z}{z(z-2)}\, \mathrm{d}z = 2\pi \mathrm{i} \cdot \frac{\mathrm{e}^2 - 1}{2} = \pi \mathrm{i}\,(\mathrm{e}^2 - 1)$

要点: 曲线在哪个圆环域内, 就在哪个圆环域内展开 —— 选错圆环, 系数就错了.

4.2 洛朗之后 · 留数定理的诞生
转折点: 本节 4.1 得到一个极其简洁的结论 —— $\oint_C f(z)\,\mathrm{d}z = 2\pi\mathrm{i}\,c_{-1}$. 这个 $c_{-1}$ 只跟洛朗展开的一项有关, 却"管住"了整条曲线上的积分. 这正是留数定理的雏形: 这一项后来被命名为 $f(z)$ 在 $z_0$ 处的留数, 记作 $\mathrm{Res}[f, z_0] = c_{-1}$.
留数定理 (第五章的核心定理)

设 $f(z)$ 在区域 $D$ 内除有限个孤立奇点 $z_1, z_2, \cdots, z_n$ 外处处解析, $C$ 是 $D$ 内包围这些奇点的一条正向简单闭曲线, 则

$\oint_C f(z)\, \mathrm{d}z = 2\pi \mathrm{i} \sum\limits_{k=1}^{n} \mathrm{Res}[f, z_k]$

也就是说: 沿闭曲线的积分, 等于曲线内部各奇点留数之和的 $2\pi\mathrm{i}$ 倍.

为什么这条定理如此重要? —— 计算方式的革命
在第五章之前, 计算 $\oint_C f(z)\,\mathrm{d}z$ 只有两条路: 一是参数化硬算 (把 $z = z(t)$ 代进去做实的定积分), 二是本节学的洛朗展开取 $c_{-1}$.
前者对复杂被积函数几乎不可行; 后者需要能把函数展成洛朗级数, 遇到分母因式多的情况也很吃力.
留数定理把这两个难点全部绕开: 只要能数出曲线内有几个奇点、各是什么类型, 代入对应的留数公式 (可去奇点留数为 0, $m$ 阶极点有现成公式), 一步就能得到积分值 —— 一个积分问题, 变成了一道"找奇点"的填空题.
洛朗 → 留数 → 更多: 一条不断延伸的路线
  • 洛朗级数是"源" —— 它把函数在奇点附近的行为完全展开, 使 $c_{-1}$ 有了明确的定义.
  • 留数是"用" —— 只取 $c_{-1}$ 一项, 就把围道积分算清楚了.
  • 再往前是"实积分的计算" —— 把实轴上的定积分 (如 $\int_{-\infty}^{+\infty} \frac{\mathrm{d}x}{1+x^2}$) 视为复平面上大半圆围道的极限, 用留数一键求出. 这是留数定理最受工程学科欢迎的应用.
  • 更远是"辐角原理与儒歇定理" —— 由留数定理变形而来, 用于数零点个数、判定控制系统的稳定性.
思想史 · 从"被搁置的论文"到"标准工具" 洛朗 1843 年把论文投给巴黎科学院时, 因为柯西未作推荐, 手稿被搁置了近二十年 (详见下一栏思政园地). 而由它引出的留数理论, 反倒因为柯西本人自 1826 年起就在发展, 得以迅速传播.
历史在这里留下一个意味深长的对照: 洛朗给出了工具, 柯西给出了方法论, 而真正把两者合成"标准武器"的, 是 19 世纪后半叶的一整代人.
今天, 从电路分析中的传递函数求逆, 到量子力学里的散射振幅计算, 再到控制理论中的稳定性判据, 走的都是同一条路: 把函数在奇点附近的洛朗展开取出一项, 然后让 $2\pi\mathrm{i}$ 把它变成答案. 那是一份 1843 年被搁置的手稿, 在 180 年后依然在工科实验室里日夜运转.

6.1 数学家故事 · 洛朗: 在工地上写下圆环的人

工程师的逆袭 · 洛朗的圆环

在幂级数失效的地方, 洛朗级数为奇点周围的世界立下了规则
"数学不在乎你的出身, 只在乎你的严谨."
洛朗 (Pierre Alphonse Laurent, 1813—1854) 是一位海军工程师, 长期在阿尔及利亚从事港口工程建设, 数学完全靠业余自学. 他关于洛朗级数的论文生前未能发表 —— 提交时评审人柯西因故搁置, 等到正式刊登时, 作者已经去世. 然而时间最终站在真理一边: 今天, 每一个研究奇点的人都在使用"洛朗展开".
1813 年 7 月生于巴黎
皮埃尔·阿方斯·洛朗 (Pierre Alphonse Laurent) 出生于巴黎一个普通家庭. 时代的法国正处在科学与工程并进的年代 —— 综合理工学院 (École Polytechnique) 人才辈出, 柯西、刘维尔的名字已在数学界回响.
1830—1832 年考入巴黎综合理工学院
17 岁的洛朗考入这所法国最负盛名的工程师摇篮. 在这里他系统学习了分析力学与数学分析 —— 柯西刚刚建立的复积分理论正是当时的前沿. 毕业后他没有留在学术圈, 而是选择成为一名军事工程师, 从此终身与港口、堤坝、要塞打交道.
1832—1840 年远赴阿尔及利亚 · 深夜的数学
法国占领阿尔及利亚后, 大兴土木: 阿尔及尔港的扩建、防御工事与供水工程都需要工程师. 洛朗被派往北非, 一待就是多年. 白天勘测、绘图、指挥施工; 晚上在油灯下演算数学 —— 没有导师, 没有同事讨论, 没有图书馆, 全凭在综合理工学院打下的功底自学.
正是在这片工地上, 他注意到一个"缝隙": 柯西积分定理只在圆内有效, 一旦函数在圆内有奇点, 泰勒展开就失效了. 可是围着奇点的圆环呢? 那里函数明明解析!
1843 年 6 月论文呈送巴黎科学院
洛朗完成了题为《柯西定理的扩充》的备忘录 (mémoire): 证明在圆环域内解析的函数可以展开为双边幂级数, 并给出系数的积分公式 —— 这就是今天的洛朗定理. 他把论文寄回巴黎科学院, 希望得到权威的评审与发表. 此时他仍是一个无学术头衔的现役工程师.
1843—1854 年被搁置的十年
评审人正是复分析泰斗柯西. 柯西意识到洛朗的结果与自己 1831 年在意大利得到的未发表结论相重合, 既没有给出否定的评审报告, 也没有推荐发表 —— 论文就此被压了下来. 洛朗多次催问无果, 只能继续他的工程事业, 后来转任布伦港 (Boulogne-sur-Mer) 的工程职务. 1854 年 9 月, 洛朗病逝, 年仅 41 岁, 终生未能亲眼看到自己的定理付印.
1863 年身后九年 · 论文终于发表
洛朗去世九年后, 这份备忘录经人整理, 刊登于《综合理工学院学报》(Journal de l'École Polytechnique) 第 23 卷. 数学界最终承认: 在圆环域上展开解析函数的优先权属于洛朗. 柯西当年的一次迟疑, 让这一成果迟到了整整二十年.
19 世纪末至今圆环成为标准语言
洛朗级数很快成为复分析的地基: 魏尔斯特拉斯学派用它定义奇点(可去奇点、极点、本性奇点), 留数理论由它而生. 到 20 世纪, 它进入信号处理 (Z 变换)、空气动力学 (奇点法)、电磁仿真等领域 —— 中国"天河"超算上的场仿真、国产大飞机的气动计算, 数学内核里都有那个圆环.
洛
洛朗 (P. A. Laurent, 1813 — 1854)
法国军事工程师 · 业余数学家 · 洛朗级数创立者 · 终年 41 岁

洛朗生前没有教授职位、没有学术头衔、没有一篇发表 —— 他唯一的一次投稿被搁置二十年, 以身后刊出的方式与世人见面. 然而今天, "洛朗级数"与"洛朗定理"写进了全世界每一本复变函数教材, 与泰勒、柯西这些如雷贯耳的名字并列.

他最了不起的地方, 是研究视角的转换: 前人把奇点当作幂级数展开的"禁区", 绕开它走; 洛朗却在奇点周围画一个圆环, 把坏点隔离在外, 在环内重建展开理论 —— 甚至让负幂项反过来精确刻画奇点的性质. 这种"在缺陷处建立秩序"的思路, 正是洛朗级数留给后世最宝贵的方法论遗产.

他的故事说明: 热爱与坚持可以跨越身份的边界 —— 正如洛朗级数跨越了泰勒级数的边界. 白天是军港工地上的工程师, 深夜是探索无穷的数学家, 两个身份在他身上并不冲突, 反而互相成就: 工程的严谨让他尊重每一个系数, 数学的想象让他不满足于"圆内"的世界.

1史料细节: 那份被搁置的备忘录

洛朗 1843 年呈送的论文标题为 Extension du théorème de M. Cauchy relatif à la convergence du développement d'une fonction suivant les puissances ascendantes de la variable (《柯西函数依变量升幂展开收敛性定理的扩充》). 从标题即可看出他的定位: 不是另起炉灶, 而是把柯西—泰勒的展开定理推广到圆环域.

评审过程一波三折: 柯西 1831 年在意大利都灵期间确实已独立得到类似的展开 (他本人在 1841 年的一篇自印文章里提及), 因此面对洛朗的工作, 柯西处境尴尬 —— 既不便否认其价值, 又不愿承认自己二十年前"做而不发". 论文最终未获推荐发表, 直至洛朗身后才由他人整理刊出. 这段公案至今仍是科学史上"评议延迟"的经典案例.

2两份职业, 一种精神

有趣的是, 洛朗的工程生涯本身也在印证他的数学思想: 修港口要先划定施工域 —— 哪里能建、哪里是深水航道不能碰, 边界必须一清二楚. 这与洛朗定理"先定圆环域, 再展开"的顺序如出一辙; 负幂项刻画奇点, 就像工程图纸上专门标注的暗礁位置 —— 不回避危险点, 而是精确标定它.

回到课堂: 我们解例 3.2 时"先画域、再展开"的习惯, 正是这位工程师数学家留下的职业规范. 数学分析与工程实践, 在洛朗身上完成了一次无声的握手.

轶事洛朗并非孤例. 魏尔斯特拉斯同样出身平凡 —— 中学教师出身, 在乡间中学教书时坚持研究函数论, 后来成为"现代分析之父"; 中国的华罗庚早年也只有初中学历, 在杂货柜台后自学成材. 洛朗、魏尔斯特拉斯、华罗庚的故事共同印证: 学术面前, 出身不是边界, 坚持才是通行证.
◈ 洛朗的心境
论文被压了十年, 洛朗没有停止演算, 也没有停止修港口. 他大概是这样想的:
"定理的价值不取决于它何时被承认 —— 我只负责把它算对, 剩下的交给时间."
1873 年, 德国数学家魏尔斯特拉斯在柏林的一次讲演中, 明确把圆环内展开的荣誉归于洛朗. 此时距洛朗去世已近二十年. —— "我只负责把定理算对, 剩下的交给时间." 这份定力, 是所有认真做事的人共同的底色.
6.2 数学家故事 · 柯西: 那位"看走了眼"的评审人
柯
奥古斯丁-路易·柯西 (Augustin-Louis Cauchy, 1789—1857)
法国数学家、物理学家 · 巴黎科学院院士 · 复变函数论的奠基人 · 分析严格化运动的旗手

在本节的故事里, 柯西扮演了一个复杂的角色: 他既是洛朗定理所属学科的奠基人(没有柯西积分定理, 就没有洛朗定理), 又是让洛朗论文迟到二十年的评审人.

要公正地看待这段历史, 就不能只看"搁置"这一面 —— 还得看见: 洛朗级数之所以能被称为"柯西定理的扩充", 恰恰因为柯西已经把地基打得足够坚实.有时候, 一个人既是障碍, 也是阶梯.

1奠基: 洛朗定理脚下的那块地基

柯西在 1825—1831 年间建立了复变函数论的两块基石: 柯西积分定理(解析函数沿闭曲线的积分为零)与柯西积分公式($f(z_0) = \frac{1}{2\pi\mathrm{i}}\oint \frac{f(z)}{z-z_0}\mathrm{d}z$).

本节用到的洛朗系数公式 $c_n = \frac{1}{2\pi\mathrm{i}}\oint \frac{f(z)}{(z-z_0)^{n+1}}\mathrm{d}z$, 形式上几乎就是柯西积分公式的直系后裔. 洛朗本人也毫不讳言 —— 他论文的标题就写着"柯西……定理的扩充".

2未发之稿: 为什么柯西会"压稿"

柯西 1831 年在意大利都灵流亡期间, 其实已经独立得到了圆环域上的展开结论, 但没有正式发表(只在 1841 年的一篇自印小册子中提到). 因此当 1843 年洛朗的论文送到他手上时, 他的处境相当微妙:

若推荐发表, 等于公开承认"洛朗先把它写清楚了"; 若否掉, 又与事实不符. 结果他选择了最消极的一种 —— 既不推荐, 也不否定, 让论文静静躺在那里.

这是人之常情, 却是学术制度的大忌. 这段公案后来成为"利益冲突应由第三方评审"这一现代学术规范的重要历史注脚.

3另一桩: 他也压过阿贝尔的稿子

这不是孤例. 1826 年, 挪威青年阿贝尔(见第四章第一节思政栏)把幂级数收敛半径的奠基性论文呈送巴黎科学院, 负责审阅的同样是柯西. 柯西读后评价"非常好", 然后就把它放进了抽屉 —— 阿贝尔至死没能看到自己的论文发表.

连续两次"看出价值却不推一把", 这对柯西来说是一份沉重的历史评价. 但他也并非心胸狭隘: 1826 年阿贝尔公开指出他"通项趋零即收敛"的错误时, 他坦然接受并修正了结论.

⚔ 历史公论: 柯西的两副面孔
作为奠基人: 他把极限、收敛、积分建立在严格定义之上, 复变函数论的每一次推进都踩着他的地基. 今天复变函数课程里出现最多的姓氏, 就是"柯西".
作为评审人: 他两次(阿贝尔 1826、洛朗 1843)一眼认出划时代成果的价值, 却都因事务积压与处境尴尬而搁置, 让两位年轻人在生前没能得到应有的承认.
历史给我们的启示: 识别价值固然是能力, 让价值及时实现才是责任. 这也提醒今天的我们: 与其抱怨"没被看见", 不如先让自己成为那个"看见并愿意推一把"的人.
6.3 数学中的哲学: 圆环里的智慧
哲学视角

圆环里的辩证法

泰勒级数只能容纳"圆内的完美", 洛朗级数却容纳"圆环上的缺陷": 负幂项(主要部分)恰恰描述了奇点附近的行为. 正视缺陷, 才能完整刻画世界.

负幂部分 = 主要部分: 在奇点附近, "病态"的部分反而携带了最关键的信息.
方法论

一函数多展开

同一个 $\frac{1}{(z-1)(z-2)}$, 在四个圆环域内有四副面孔. 立场(区域)变了, 结论就变 —— 分析问题先明确前提与范围.

先画域、再展开: 做事先看清"边界条件", 是工程师洛朗留给我们的职业习惯.
量变质变

一个系数, 决定一切

$\oint f\,\mathrm{d}z = 2\pi\mathrm{i}c_{-1}$: 艰难的围道积分, 竟只需读出展开式的一个系数. 而这个 $-1$ 次项, 正是整个级数里最"反常"的那一项.

最关键的信息常常藏在最不起眼的位置 —— 留数定理的全部力量, 都压在一个 $c_{-1}$ 上.
整体观

由局部刻画奇点

可去奇点(无负幂项)、$m$ 阶极点(负幂项有限)、本性奇点(负幂项无穷) —— 奇点这样"最不解析"的对象, 反而被展开式的局部结构完全刻画了.

奇点的类型 $\iff$ 洛朗展开中负幂项的多少  ·  认识一个人, 常看他"出问题时"的表现.
科学精神

评议延迟的教训

洛朗的论文迟到二十年, 阿贝尔的论文至死未发. 科学的进步不只依赖天才的灵光, 也依赖一套让好成果及时被看见的制度与人心.

严谨的成果最终会被时间识别 —— 但让"识别"来得快一些, 是每一个学术共同体的责任.
家国情怀

展开即积累

平时把"级数"(基本功)展开到位, 关键时刻自然水到渠成. 洛朗白天修港口、深夜算级数, 靠的就是日复一日的积累.

平时的每一项积累, 都是未来某次"积分"的 $c_{-1}$ —— 量变到质变, 从来不靠侥幸.
6.4 古今对话: 从"格物致知"到"奇点上的中国算法"
中国智慧中的"穷理"传统
中国古代学术讲究"格物致知"—— 即通过穷究事物的道理来获得真知. 洛朗的贡献恰恰是这种精神的体现: 别人把奇点当作绕道而行的"禁区", 他却把奇点当作研究对象, 穷究其内在结构, 最终用负幂项精确刻画了奇点.
从《九章算术》"析理以辞, 解体用图"的注释传统, 到刘徽"割之又割"的极限实践, 中国古代数学一直有追问"为什么"的血脉. 洛朗级数虽诞生于法国, 但它所体现的"穷究疑难、在缺陷处建立秩序"的精神, 与中国学术传统是相通的.
现代回响: 洛朗展开的当代身影
  • 信号处理与 5G 通信: 数字滤波器设计中广泛使用的 Z 变换, 本质上就是"离散版的洛朗级数". 收敛环的内外半径直接决定系统稳定与否 —— 洛朗当年画的那个圆环, 今天每天都在为数十亿次通信把关.
  • 航空与流体力学: 计算翼型周围的流场时, 常用的"奇点法"把复杂流场表示为若干奇点(源、涡、偶极)的叠加 —— 这正是洛朗展开"用负幂项刻画奇点"思想的工程版本. C919 的气动设计里, 有洛朗的影子.
  • 电磁仿真与超算: 在天河、神威等国产超级计算机上运行的电磁场仿真程序, 其核心算法多涉及奇性分解与留数计算 —— 数学内核里都有那个圆环.
  • 华罗庚与多复变函数论: 华罗庚在典型域与"华氏算子"上的开创性工作, 建立在多元幂级数(洛朗展开的现代推广)理论之上, 为中国数学赢得了世界声誉.
思政启示: 在"缺陷处"建立秩序
洛朗最可贵的精神, 不是他有多聪明, 而是他敢于把研究的目光投向别人绕开的地方. 泰勒级数遇到奇点就"失效", 洛朗却在奇点周围画了一个圆环, 把坏点隔离在外, 在环内重建了完整的展开理论.
在工程与科研的实践中, 我们同样会遇到无数"奇点": 卡脖子的技术难点、系统中最脆弱的环节、模型里最反常的数据. 把它们当作研究对象而不是绕开的障碍, 才是突破的来源 —— 哪里最困难, 哪里就是理论的生长点.

本节思政小结
一个故事: 洛朗是阿尔及利亚工地上的一名海军工程师, 白天修港口、深夜算级数. 1843 年他把"圆环域上的展开定理"寄给巴黎科学院, 评审人柯西因处境尴尬而搁置; 论文在他去世九年后(1863)才终于发表, 而他 41 岁便已病逝 —— 今天全世界每一本复变函数教材里, 都写着"洛朗级数".
一个道理: 泰勒级数遇到奇点就失效, 洛朗却在奇点周围画一个圆环, 把坏点隔离在外, 用负幂项反过来精确刻画它 —— 不回避缺陷, 而是把缺陷变成观察对象, 这是本节最宝贵的方法论. 同时, 洛朗与阿贝尔的遭遇提醒我们: 科学的进步既依赖天才的灵光, 也依赖"让好成果及时被看见"的制度与人心; 识别价值固然是能力, 让价值及时实现才是责任.
一份责任: 从洛朗"先划定施工域、再动手施工"的工程规范, 到刘徽"割之又割"的穷理传统, 再到今天 Z 变换、奇点法、电磁仿真里那个无处不在的圆环 —— 数学的严谨从来没停在纸面上, 它是 5G、大飞机与超算背后的沉默基石. 在"缺陷处"建立秩序, 在"卡脖子"处寻找突破, 是我们这一代科技工作者对国家最实在的担当.
